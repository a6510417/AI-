# 23_素材来源与发布前检查技能

整理本次作品实际使用素材的来源、使用范围和证据，并完成对外发布前的内容、文件和渠道检查。用于参考图、音视频、字体及成片交付；不以技术核对出具法律结论，不把发布准备自动扩为发布操作。

共同边界见[工作室执行规则](../docs/工作室执行规则.md)，内容与成片结论继承11、22，填写[来源与发布模板](../模板库/23_素材来源与发布检查模板.md)。只审本次实际使用或计划使用的范围，不要求清查无关素材库。

## 一、来源、用途和证据

逐项记录素材具体文件／网址、提供者或取得方式、实际取得日期（已知时）、使用用途及范围、可核对的许可／授权／用户说明。分别标明仅参考、输入生成工具、用于成片、用于封面／宣传；一种用途的证据不自动覆盖其他用途。

- 图片、视频、声音、音乐、字体、图形与模板分别登记必要来源；平台内置素材也记录所用条目和本次可查使用说明，不因能下载就称可用于所有发布渠道。
- 原创生成记录真实工具、提示词与参考来源；原创设计不等于引用的外部参考已经审过来源。未取得结果时只列拟用，不伪造生成凭据。
- 用户提供或报告已获授权时如实保留依据与适用范围；没有看到原证明就标“用户说明，未查看证明”，不伪称已经核验原文。
- 涉及特定真实人物形象或声音时，记录本次用途的真实授权证据或缺项，不自动克隆、借用其声音。普通原创角色不因此被要求提供不存在的真人授权。
- 保存依据链接、文档版本／日期及实际阅读范围。来源网页、许可或服务规则缺失时写证据不足，技术记录不能证明一切权利已获许可；有明确冲突则定位受影响素材与交付。

## 二、发布前工作流程

1. **确定本次交付**：区分本地交接、发布包准备和实际发布；登记渠道、账号范围、作品版本及当次授权，未指定渠道不编平台要求。
2. **整理使用清单**：从真实成片、封面、配乐和字幕／字体取用回查本次来源，区分备用素材和实际进入交付的素材。参考只借某项时说明采用与未继承内容。
3. **核对证据范围**：对已查资料记录适用用途、期限、地域／渠道及署名要求中实际相关的部分；未知保持未知，不把“无署名要求”从没看到要求推导出来。必要法律判断交给合适专业人员，本技能只指出具体证据和待核验问题。
4. **检查作品与包装**：继承22的确切导出及审片范围，检查标题、简介、封面、字幕、片内文字、署名和素材替换是否与当前作品一致；营销文案不得虚构剧情、成绩或授权身份。
5. **核对当前渠道**：只有任务需要该渠道时读取官方发布要求及实际入口，记录规格、内容或标识要求与来源日期。账户功能、上传档位及开关未经查看不填为已设置；本地文件合格不等于平台已审核通过。
6. **交付准备包**：给出确切文件、包装文字、证据范围、待解决项和发布操作单。来源/成片关键项未核实的受影响版本不能标为已完成发布检查；其他可独立资料继续整理。
7. **记录实际发布**：明确授权且有可用入口时才执行实际操作。分别记录上传、提交、平台返回、公开可见、定时或审核中；没有真实链接、时间和返回不编记录。实际发布后的指标交24，不提前写成有效传播。

## 三、验收与保存

每个本次进入交付的素材能定位到真实来源、用途、证据和结论。结论使用限定范围的“已核对／证据不足／发现冲突／不适用”，不使用笼统的“版权全部安全”。发布准备可以完成而实际发布未执行，两者分别报告；对外渠道通过也不替代成片内容审看。

清单与证据可作REPORT附件，按[数据协议](../docs/数据协议.md)固定引用所需采用资产；失败或未采用证据用普通文本定位和附件，不为出包采用未通过素材。不要在模板写入账号密码、密钥或无关个人信息。

**简短调用：**使用23，检查这集实际使用的图片、对白录音与字体来源，并整理本地发布准备包。未指定发布账号、没有渠道当前规则，请列具体待核验项，不上传、不宣布全权利已确认。

共同执行要求：[工作室执行规则](../docs/工作室执行规则.md)；来源和状态口径：[AI执行规范](../docs/AI执行规范.md)；正式字段和固定版本引用：[数据协议](../docs/数据协议.md)。跨阶段只按任务读取12或17，本阶段不扩展已明确的交付范围。
