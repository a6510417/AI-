# 18_动作与特效导演技能

将打斗、法术和宏大奇观变成空间清楚、阶段明确、可拆镜和可检查的动作设计，再交付可复制提示词。适用于近身攻防、兵器交锋、多人围攻、法相显现、巨物降临及其他需要环境反馈的特效；普通对话、静态定妆不必加载本技能。

这是项目内的中文 Markdown 技能。可承接06的剧情，供07拆镜、08摄影、09提示词、10适配、11质检使用；用户直接要一条提示词时，也可独立处理信息足够的任务，不要求先建完整IP或运行全部阶段。

## 特殊运动与静态关键帧分工

飞行、载具、水下、兽类、变身、召唤和瞬移按需读取[特殊运动与形态变化](../知识库/12_特殊运动与形态变化参考.md)：先确定主体起止、支撑或媒介、路径、接触和世界规则，再交08安排摄影。合法形态变化与身份错误分开；不套用近身攻防链强制添加敌人。

需要图片时点和序列时交[19_关键帧与冲击帧技能](19_关键帧与冲击帧技能.md)，18仍是动作因果与阶段依据。抽象冲击帧可以暂时改变色彩、明暗或形状表现，不能用它掩盖未设计的接触、偷换兵器或改写结束状态。

## 一、先确定任务和设计权限

- 读取实际提供的故事、角色、场地、动作结果、风格及参考；说明来源与采用状态。沿用[AI执行规范](../docs/AI执行规范.md)，不把新设计冒充原文，不伪造章节、资产版本或参考观察。
- 用户明确要求法相、巨剑或某种招式时，可以直接设计必要的姿态、显现、投光和摄影。改变既定胜负、伤亡、能力边界或永久场地状态，应按已有改编权限处理；权限不足时只标出该项，继续完成不受影响的视觉方案。
- “宏大、震撼、电影级”是目标，必须展开成尺度、空间、运动、光照和反馈。不能靠增加世界规则、杀伤范围或人物数量来代替视觉设计。
- 原作已发生的学习、魂穿、记忆传递等过程，可以在改编权限内设计明确的主观空间和能量形态，不限于微光或提示字幕。意识中金人演拳属于教学表现时，写清与主角领悟、现实动作的联系及外界时间衔接；它不自动成为现实召唤、代打或高阶法相。保护功能与时点，不能把“原文未写特效细节”或旧稿低强度设计当成禁止发挥的依据。
- 只有题材词时，可给一套标为“原创建议”的明确方案。影响结果的歧义如“落地摧毁还是悬停威慑”必须说明所选方案；用户已给答案时直接沿用。忠实复原任务不能用建议填补关键事实。
- 默认中文文字交付。目标平台、模型版本和模式未定时仍可交付通用稿；缺参考时写文生方案或待参考草案，不伪称素材已绑定。实际生成和媒体检查分别记录。

## 三、建立本段的空间与状态基准

先继承06的导演作用和本轮G／K／L等权限：这次动作要翻转哪种压力、显出怎样的角色习惯，效果要让观众读出什么功能。技能机制、可复用特效形态、服装、武器与配饰按精确基准引用；本段只设计施展过程与环境反馈。动作需求可回传服装活动空间，不自动加护甲、护腕或背刀；未锁定组件提出设计需求，不在提示词中静默定稿。

1. 用稳定的场地参照定位人物、目标、落点、障碍和观察侧。身体左右、画面左右和场地位置分开；反打能改变画面左右，不能偷偷交换攻守者。
2. 记录每个关键参与者的起点和终点：身份、朝向、站位、支撑、持物、损伤和正在进行的动作。背景参与者也须知道是在逼近、等待、退避还是已经倒地。
3. 巨物用同框的人、台阶、建筑、山峰或云层建立相对大小。文字数值仅在已有设定或获准设计时使用，不冒称实测；换景别不能把巨物缩回普通体型。
4. 区分物体运动、摄影机运动和镜头剪辑。需要跨行动线、换观察侧或遮挡转接时，给出能重建空间的画面；不能用突然换景掩盖位移。
5. 只把本镜实际需要的状态放进可复制正文；全段台账保留跨镜依据。结束状态必须成为下一镜起点，不能自动修复破损、恢复阵法或重新复制武器。

用障碍脱围时检查当时的直线路径：柱、墙或其他障碍实际位于谁与谁之间，谁因此绕行，谁只是因起步较晚或距离较远而落后。同侧追赶不能只靠“石柱阻隔”解释安全脱离；需要可读的间距、先后或避让动作。

## 四、攻防设计：把接触与回应写清楚

为每次决定观感或结果的交锋写出：**发起者与目标 → 起势/距离 → 攻击路径 → 对方应对 → 接触、格挡或落空 → 身体/武器反馈 → 收势与下一拍条件**。不强制每一步单独成镜，也不为展示威力擅加连击。

- **近身**：写明哪只手脚、朝向哪一处、对方如何避让或防守；位移来自跨步、转体、受力或已采用能力。空击不能无因让对方倒飞，闪避不能以身份互换完成。
- **兵器**：写明持械者、持握手、剑刃或棍身的路径、接触部位及分离方向。格挡的接触与受力反馈可见，武器不跨镜换手、伸长或复制；合法换手须有动作依据。
- **反馈**：选择能看见的支撑变化、肩臂带动、后撤、落脚、衣物惯性、火星或碎屑。风格化力量可以超出现实，但反馈方向、能力来源和故事结果仍要自洽。
- **多人**：每镜优先突出一个主要攻防关系，交代其余人的状态。多个同时接触和交叉路径都重要时，拆回合或用宽景建立关系，不把人数上限写成模型通用规则。
- **摄影与节奏**：默认一个清楚的主要观看任务和摄影意图；并非禁止组合运动。动作密度与运镜密度分别控制，连续招式、复杂摄影、强遮挡叠加时先减掉不承担叙事的复杂度。

没有实测，不规定“每秒必须几招”或“15秒必须几镜”。用户要求一镜到底时先保留连续意图，给出可实施的减复杂度方案；拆镜作为明确备选，不能默默替换。

## 五、宏大特效：形态、阶段和环境共同成立

### 特效卡的必要内容

| 维度 | 写清什么 | 常见失效 |
| --- | --- | --- |
| 来源与数量 | 由谁/何处触发，单体、群体还是连续流 | 巨剑变剑雨，法相变第二名普通角色 |
| 形态与材质 | 实体金属、半透明能量、烟云或其他明确媒介；轮廓与颜色 | 所有效果都变成不分形状的光球 |
| 尺度与位置 | 与人物、山门、山峰的比例；前中后景及锚定位置 | 只有“千丈”却没有尺度证据，跨镜缩小 |
| 时间阶段 | 本段经历哪些阶段，起点、高潮、终点分别是什么 | 开场已经完成显现，阶段重复或跳过 |
| 运动与目标 | 方向、路径、接触目标、落点或悬停位置 | 剑尖翻转、落点漂移、先爆炸后接触 |
| 环境交互 | 遮挡、云层分离、衣物响应、接触处破坏与残留 | 特效像贴纸，烟尘无来源，破坏下一镜恢复 |
| 光照与曝光 | 光来自哪里、照亮谁、反射到哪里、何时增强和衰减 | 全画面持续泛白，脸部和接触点消失 |
| 声音与结束 | 蓄势、运动、接触、余音对应的事件；保留或消散什么 | 冲击声提前、每镜重复同一次爆发 |

阶段可选择 **预兆→聚集→成形→释放/移动→接触→余波/消散** 中真正需要的部分。展示型奇观可以停在成形；不要求每次都攻击、爆炸或摧毁。预先吸起的尘粒与接触后扬起的尘浪应有不同来源，不能一律禁止接触前出现任何尘土。

### 法相天地

先锁定“本体巨化”“身后能量法相”或“独立化身”。含糊的创意请求可建议一种并标明；不要把三者混成一个过程。身后法相须保持真实人物体型，说明法相数量、相对位置、显现顺序、轮廓、透明度层次与动作联动。云雾可遮住法相的部分体积，局部投光随显现增强；纯能量体不必像实体雕像一样投出浓黑阴影。只有叙事需要时才安排法相出手。

### 巨剑从天而降

先锁定单柄或剑雨、实体或能量、出现方式、剑尖朝向、目标和结局。巨大实体可通过遮云、投影、较长穿云路径与固定地标建立尺寸；发光剑则补充局部环境回光。写清“下落到接触”与“接触后的反馈”，不能以满屏闪白跳过关键因果。结尾若插地则保留插入角度、深度关系和裂纹；若悬停就不提前生成落地坑。

### 控制可读性

前景可用人物或地物建立比例，中景承载主效果，后景提供深度；这只是组织方法，不要求每镜凑齐三层。火星、符纹、粒子、云雾各服务一个作用，不把每层都铺满。辉光、拖影、震动和尘幕可以使用，但注明出现节点，并保留观察关键轮廓、攻击路径或接触前后关系的画面。

## 六、UE5观感与三维国漫半写实

本轮示例选择三维国漫半写实、面向即梦网页/App。**这不是其他项目的强制默认**；用户风格和已采用基准优先。

- 风格段分别决定：角色比例与造型、布料/金属/岩石等材质、连续明暗、环境照明、法术发光、色调和细节层级。不要仅堆“UE5、8K、顶级渲染”。
- 保留国漫人物辨识特征，三维材质不等于改成真人脸、加毛孔或改变年龄。服装基础色与光照偏色分开。
- Lumen、Nanite、Niagara可以是沟通线索，交付应落到回光、表面细节、可见粒子等效果；不将这些词、采样数或引擎配置当作即梦已经执行的参数。真正的UE工程制作另行处理。
- 同一表面上的纯平涂与连续写实明暗冲突时，选定表达或明确分层。二维角色配三维场景可以是合法设计；只有用户确实要这种混合时才保留，不能自动判为禁止。
- 二维角色参考用于身份时，说明保留脸型、服装和色彩，三维材质为本次转换目标；作为严格首帧时若画风冲突，先准备相容首帧，不能一边硬锁二维起点一边保证全程三维。
- 外部模板中的 `no CGI`、`no 3D`、`never CG` 仅作冲突示例，不能流入本预设的负面正文。也不要为模仿UE5自动加入游戏HUD、血条或UI。

## 七、输出：设计说明与可复制正文分开

完整任务交付以下内容；用户只要单镜时合并重复记录，保留影响该镜成立的项。用户只要视频正文或其中一类提示词时，设计过程可内化，只交所需正文和必要缺项说明，省略未请求的栏目；不强制额外交付完整镜头卡、首帧或特效表。

1. **依据和设计说明**：范围、授权、起止状态、空间/尺度基准、攻防链或特效卡、风格和仍缺的信息。
2. **逐镜方案**：请求完整分镜时沿用07的十一项，包括实际视频提示词；单条提示词任务把必要内容落实在正文中，无须附整套镜头表。制作时长是规划，注明估算依据，不承诺模型逐秒或逐帧遵循。一个镜头中的多拍动作不自动拆成多次生成。
3. **按请求交付提示词**：完整包包含视频、图片、负面处理、优化建议；单类任务只保留所需项。每镜视频正文独立说明主体、起点、必要过程、终点、摄影、光影与风格；首帧图片只描述该镜起始的一个时点，不提前呈现完成态。完整设计不要整段重复塞进每条正文。
4. **参考职责**：人物身份、服装、比例、场景、风格、动作、摄影、首/尾帧和声音分别登记，说明采用与忽略的内容。比例参考不自动固定背景，动作参考不自动更换角色。
5. **检查和最小返修**：明确文字已查范围，实际图片/视频是否查看，指出下一次只需改哪组变量。

即梦网页/App以可复制中文及素材操作说明交付，具体版本、入口和模式由[10_模型适配技能](10_模型适配技能.md)核实。未经核实不杜撰独立负面栏、参考上限、时长档位或API字段；排除要求可作为项目检查清单，并将关键约束改成正向保持表达。首尾帧、动作视频和多参考能否组合须核对所用模式，不从另一入口推断。

复杂效果未成功时，先定位问题：比例错误修尺度参考；像贴纸修遮挡/材质/光照；阶段漏掉则拆段；接触不清先简化摄影与遮挡。不要统一退化为“激烈战斗”“宏大能量”，也不要未经同意缩小巨物、删掉高潮或改变结局。

## 八、检查与现有资产交接

- 文字检查：攻守身份、路径、接触/落空、受力、比例、阶段、结束状态、风格是否自洽；首帧是否和视频起点一致；排除要求是否误禁合法变化。
- 媒体检查：有实际文件才核对角色漂移、穿插、滑步、剑体数量、尺度变化、特效遮挡和声画同步。接触前后及跨镜连接须连续观看，抽帧只能说明被查看的瞬间。
- 返修记录指向具体镜头、位置、原因与版本。缺少实片时仅判文字设计，不记录视觉一致性通过。
- 07保留镜号、十一项、来源与切点；08保留观察侧、清晰范围和摄影意图；09压缩成独立正文；10做入口映射；11分别登记文字与媒体证据。04承接持物/损伤，05承接场地与照明的实际变更。

| 设计内容 | 现有机器字段/交付位置 |
| --- | --- |
| 攻防、阶段、接触与反馈 | SHOT `action`，完整设计作为该资产目录内的文字附件 |
| 人物/巨物关系与尺度 | `visual_description`、`scene_description`，必要时写入可复制正文 |
| 特效投光与摄影 | `lighting`、`camera_movement`、已有 `photography` |
| 跨镜持物、损伤、剑体或场地残留 | 已有 `entry_state`、`exit_state`；按任务同步STATE/LOC |
| 生成正文和排除检查 | SHOT `video_prompt`；PROMPT已有 `image_prompt`、`video_prompt`、`negative_prompt`、`optimization` |

映射不增加必填机器字段或新资产类型。`negative_prompt` 是本地记录，不代表平台有同名输入。正式登记遵守[数据协议](../docs/数据协议.md)，不手改历史快照；独立案例未登记时保留文字编号，不伪造CH/EP/SC引用。

方法借鉴、许可、固定版本及排除项见[开源来源与许可](../docs/动作特效开源来源与许可.md)。技能完成、提示词完成和视频验收完成分别报告。

## 精细动作与返修接入

吃喝、细小手部操作、近距离双人接触、舞步或乐器演奏读取[15_日常精细动作参考](../知识库/15_日常精细动作参考.md)和[六个完整文字例](../知识库/案例/日常精细动作完整示例.md)。沿用起点—接触—反馈—终态，但不强加攻防或冲击特效。明确每只手、物体、支撑脚和发声来源的职责，摄影保证必要关系可见，不能靠快切掩盖关键操作跳步。

实际失败、修改变量和候选选择登记[生成与返修台账](../模板库/17_生成与返修台账模板.md)。没有实片时列待查失败情形，取得结果后才登记实测时码与视觉结论。

共同执行要求：[工作室执行规则](../docs/工作室执行规则.md)；来源和状态口径：[AI执行规范](../docs/AI执行规范.md)；正式字段和固定版本引用：[数据协议](../docs/数据协议.md)。跨阶段只按任务读取12或17，本阶段不扩展已明确的交付范围。
