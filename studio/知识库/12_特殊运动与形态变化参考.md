# 12_特殊运动与形态变化参考

用于飞行追逐、载具、水下、兽类运动，以及变身、召唤、瞬移。只加载本次涉及的分支。运动因果由[18_动作与特效导演技能](../技能库/18_动作与特效导演技能.md)统筹；摄影交08，关键姿态交19，已采用角色状态交04。魔法可违反现实物理；实际作用于故事世界的能力依本轮明确来源、指定版本或已授权改编核对功能与时点，不能用特效掩盖故事要求看清的路径或凭空改变结局。

本文件的能力限制针对实际获得或使用的能力。表达已有一次性魂穿的魂影、意识空间里的能量人形授艺等，可按授权视听化，分别写清主观归属、起止与现实承接；不因出现人形或空间变化就自动视为可重复召唤、传送或代打。相应创作边界见[06剧情改编](../技能库/06_剧情改编技能.md)。

以下均为原创、未实际生成的最小文字示例；三维国漫半写实是这些例子的选择，不覆盖项目风格。示例中的人物、能力和地形仅服务演示，不自动登记为资产。

## 一、按需保留的运动骨架

**主体与运动媒介 → 起点／朝向／支撑 → 路径与障碍 → 转向或接触 → 环境反馈 → 终点与剩余惯性。**

| 可裁剪项目 | 只写影响本镜成立的内容 |
| --- | --- |
| 数量与归属 | 骑乘者、载具、坐骑、被携带物分别是谁；是否为同一主体变化 |
| 空间基准 | 可见地标、运动方向、前后距离；画面左右和人物自身左右区分 |
| 动力与支撑 | 地面、翼、游动、载具或已采用法术；悬浮能力无需硬加翅膀 |
| 关键节点 | 起动、加速、转向、通过障碍、触地或停稳；不要求每项都出现 |
| 变化与保持 | 姿态、形态允许如何改变；身份、装备和数量哪些需要保持 |
| 结束条件 | 最终位置、速度状态、持物、湿污、破损及环境残留 |

路径难以理解时先做站位／路径说明，需要独立图像时再转[19_关键帧与冲击帧技能](../技能库/19_关键帧与冲击帧技能.md)。站位图不是自动可用首帧，多格图也不保证模型按格播放。

## 二、飞行与空中追逐

区分悬浮、御物、振翅和滑翔，不用一套肢体动作覆盖不同动力。用地标说明前后、高低与转弯；摄影机追上角色不等于角色突然加速。起飞与降落涉及支撑转移，镜内没发生的阶段不强加。

**填写结构：**飞行方式与携带物 → 高度参照 → 前后关系 → 转弯路径／障碍 → 追逐结果 → 稳定终态。

**完整最小视频提示词：**

> 三维国漫半写实，晨雾山谷。黑发束髻、青衣青年双脚踩在同一柄青色飞剑上，身体沿剑身前进方向站稳；一只灰羽鹰在他后上方追赶。侧后方宽景跟随青年，保留前方石拱与谷底树冠作为高度参照。飞剑沿石拱右侧外缘弧线绕行，青年屈膝并随剑略向弯内倾斜，始终没有离开剑身；灰鹰在更高处振翅沿外侧大弧线追来，不穿过石壁。衣摆向后飘动，石拱遮挡短暂经过两者之间。结尾青年已越过石拱，灰鹰仍在后上方，双方没有接触或分出胜负。保留风声、鹰翼声，无对白。

**失败与最小返修：**上下距离丢失时保留同框地标，先减摄影绕转；飞剑与脚分离时修支撑关系及姿态参考，别泛写“完全静止”禁止转弯。用户要求着陆则补“靠近地面—减速—脚或载具接地—卸力停稳”，不能把停在半空当着陆完成。

## 三、载具行进与追逐

先区分车体、轮／履带／推进器、驾驶者与乘员的运动。 马车等牵引载具同时核对牵引动物、车辕与缰绳的连接；动力来源、操控和声音随实际类型选择，不把汽车示例的引擎声搬到马车。车体朝向与摄影运动分别描述；车辆转弯需有路径空间。乘员可以相对车厢静止，不能要求所有主体相对背景静止。

**填写结构：**载具形制与人数 → 驾驶／乘坐归属 → 道路和车道／障碍 → 一次主要机动 → 乘员与环境反馈 → 结束车位和运动状态。

**完整最小视频提示词：**

> 三维国漫半写实，傍晚空旷石板路，一辆深蓝色四轮小货车向前驶向右弯，车斗内固定着两只木箱。短发、灰色上衣的女子坐在左侧驾驶位，双手握方向盘，车内没有其他人。摄影机在车外左前方平稳后移，保持整辆车与前方弯道可见。货车先减速，再沿右弯转入石墙旁的直路；车轮贴地滚动，车身在转弯时轻微侧倾，木箱随车轻振但仍被绳索固定。结尾货车沿新直路继续前行，木箱数量和驾驶者位置不变。引擎声随减速下降再趋稳，保留轮胎碾石声，无对白。

**失败与最小返修：**外景左右改变导致驾驶位换边时，回查车体坐标而非画面坐标；车身横滑穿墙时扩大可行转弯路径或降低动作密度。确实要漂移时写明前进方向、侧滑范围和恢复抓地，不用“禁止侧滑”覆盖意图。

## 四、水下与液体中的运动

先继承已采用的闭气、装备呼吸或能力设定；只有“普通潜水”且缺少装备信息时说明本次设计假设，不凭空增加水下呼吸能力。说明是完全水下、破水面还是岸边观察；水流、人物主动游动、浮力／下沉及摄影机运动分开。泡沫和气泡要有来源，角色未呼气时不必持续产生嘴边气泡。水下声音可作风格设计，但不把空气中的清晰对白默认搬入水中。

**填写结构：**所在介质与深度参照 → 游动／漂浮方式 → 身体和衣物响应 → 接近与接触物 → 水面／水底关系 → 呼吸与声音要求。

**完整最小视频提示词：**

> 三维国漫半写实，清澈浅湖水下，阳光从上方水面形成缓慢移动的光斑。短发、深蓝贴身潜水服的青年从画面左侧水平游向右侧湖底石台，右手伸向台上的一枚铜环，左臂划水，双腿平稳打水。固定侧面中远景同时看到水面亮区、青年和石台。接近石台时他减小打水幅度，右手握住铜环后停住，身体仍在水流中轻微漂动；铜环始终在右手中，手臂没有穿进石台。湖底细沙只在近距离脚部水流影响处轻扬。全程无台词，声音为低沉水下环境与短暂划水声，结尾人物仍在水下，没有自动浮出水面。

**失败与最小返修：**衣物像处在强风中时，改为随水流滞后摆动；水下突然变陆地时重申介质边界与可见水面。任务需要原生水下对白时，沿用既有装备或魔法依据并交10核验，不未经授权改成旁白或后期配音。

## 五、兽类及非人形运动

先确认物种／结构和当前运动方式。四足奔跑、鸟类扑翼、蛇形蜿蜒与人形步态不能互换；幻想生物的额外肢体依设定保留。只描述本镜关键支撑和方向，不强制每条腿逐帧表格化。用户指定准确步数时说明本次计数口径，如单次落足、完整步态周期或身体推进节拍；口径不明且影响硬要求时保留待确认，不把三次周期悄悄当三次落足。精确步数仍须连续看片核验。

**填写结构：**身体结构与辨识点 → 当前步态／运动方式 → 起止支撑 → 转向或跨越 → 身体与尾翼联动 → 停稳状态。

**完整最小视频提示词：**

> 三维国漫半写实，黄昏松林边缘，一只四足赤狐沿林间小路向右奔跑，右耳有一处小缺口，尾尖白色。低机位侧面中远景平稳跟拍，保留脚下泥地和前方一根低矮倒木。赤狐接近倒木时收拢前肢，后肢蹬地跃过，身体越过木头后先以前足接地，再由后足承接，顺着原方向跑出两步后放慢为走。尾巴随跃起和落地调整平衡，爪下少量松针被带起。结尾赤狐仍为同一只，四肢、耳缺口和尾尖颜色保持不变。只有脚步、草叶和林间环境声。

**失败与最小返修：**兽类站成人形时，恢复身体结构和前后足支撑，优先选全身侧视参考；四足融合时减少遮挡并取清楚的起跳或落地姿态。用户需要直立兽人则沿用其结构，不能强制改回现实动物。

## 六、变身：允许变化，保持身份依据

区分换装、能量附着、局部形变、物种变化与本体巨化。只锁定变身后仍需保留的身份锚点；“任何形变都禁止”会直接否定任务。新增能力、武器、年龄或伤势必须有用户要求或已采用依据。

**填写结构：**触发 → 哪部分先变 → 哪些结构／材质变化 → 保留的身份锚点 → 装备去向 → 完成形态和身体状态。

**完整最小视频提示词：**

> 三维国漫半写实，月夜石台。棕色短发、灰色短衣、左眼下有浅色短纹的青年站在石台中央，身上没有武器或背包。固定全身中景，石台边缘始终可见。青年低头看向自己的双手，金色细光从指尖沿双臂扩展，双手逐渐变成覆有棕毛的前爪，肩背前倾，腿部随身体压低重组，短衣化为光点消散，身后生出尾巴。光雾只遮住变化边缘，保留身体轮廓。终态是一只棕毛四足狐，左眼下仍有原青年的浅色短纹作为身份锚点；四足落在石台上，停止变化后抬头望向月亮。石台大小不变，周围没有出现第二个人或第二只狐。保留轻微能量声与落爪声，无台词。

**失败与最小返修：**自动复制“人和狐”时明确同一身体变化和原形消失；全程光球掩盖变化时减少光雾范围，或把难过渡阶段拆成独立设计段。若用户允许剪辑遮转，可以给备选；要求连续可见变身时保留该目标，不能暗中用白闪替代全部过程。状态登记按[04](../技能库/04_角色一致性管理技能.md)记录合法变化。

## 七、召唤与瞬移：新实体和同一主体分开

### 召唤

召唤通常引入独立实体；区分原本已存在但从别处到来、现场凝聚成形、仅显现投影。明确数量、出现位置、与施术者关系和结束是否仍存在，展示型召唤不自动追加攻击。

**填写结构：**施术者 → 来源／介质 → 成形位置与顺序 → 被召实体数量和形态 → 结束任务与残留。

**完整最小视频提示词：**

> 三维国漫半写实，夜间石庭，黑发长辫、白衣女子站在石阶左侧，右手掌心朝上。固定宽景，石阶与庭中一株矮松可见。她掌心的青色光点落到前方空地，在她与矮松之间汇成一圈薄雾；薄雾先形成四足和躯干轮廓，再形成鹿首与双角，最终只有一只半透明青色灵鹿站在空地上。女子保持正常体型，灵鹿与她相距约一人身长，鹿角高于她的头。灵鹿微微转头看向女子后停住，青光局部照亮地面与裙摆，雾没有覆盖二者轮廓。结尾灵鹿继续存在，没有攻击、爆炸或新增鹿群；保留微弱能量声和夜风。

**失败与最小返修：**施术者变成灵鹿时分开本体与成形位置；灵鹿自动攻击时锁定本镜止于“成形并站稳”。法相需要更大尺度或特殊联动时转[09_动作特效与三维画风参考](09_动作特效与三维画风参考.md)，不重复定义法相类别。

### 瞬移

瞬移是同一主体换位置，不能无意留下永久副本。起点消失、传输效果和终点出现的先后按能力设定；如果允许残影，要说明残影性质、消失条件和是否能接触物体。

**填写结构：**同一主体及携带物 → 起点／终点地标 → 消失与出现关系 → 残影规则 → 落地／悬浮与段尾状态。

**完整最小视频提示词：**

> 三维国漫半写实，白昼石院，固定宽景同时看到左侧井台和右侧拱门。黑发束髻、灰青长衣的青年站在井台旁，右手握着一柄入鞘短剑。他脚下亮起窄小青环，身体连同服装和短剑从脚到头化成细光，井台旁清空后，拱门前出现同色细光，重新聚成同一个青年。他在门前双脚落稳，仍用右手握着同一柄入鞘短剑，抬眼看向门内。青环和细光随后消散，井台旁没有人形残影；没有奔跑轨迹或沿途爆炸。环境日光稳定，保留两次短促能量声与落脚声，无台词。

**失败与最小返修：**两端长时间同时存在时写清消失／出现顺序和残影范围；短剑消失时把其列入随身传输对象。若既有能力允许同时分身，则按分身处理，不能用本例规则删掉合法副本。

## 八、交付和验收边界

- 每条图片只冻结一个位置与阶段；连续变化放进视频正文或序列说明，不在一张单帧中要求同时呈现起跳、落地、转身。
- 在07／08的镜头设计中分别描述主体运动和摄影机运动；有意静止、固定机位或水流漂浮不是失败。
- 需要持续的湿污、变身形态、消散装备或召唤实体，写入段尾并交04／05承接；临时特效按结束规则消散。
- 原生声音、连续镜头及准确文字等用户硬要求，未验证时明确保留为待实测；不未经授权改成后期处理再报告完成。
- 验收依次看数量／归属、支撑／介质、路径／接触、合法变化、终态。无媒体时仅完成文字自洽检查，不宣称没有穿插或运动稳定。
