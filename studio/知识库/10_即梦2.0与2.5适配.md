# 10_即梦2.0与2.5适配

用于[10_模型适配技能](../技能库/10_模型适配技能.md)的按需能力资料，不是账号设置清单。核验日期：2026-09-30。目标模型为 **Seedance 2.0／Seedance 2.5**；不能仅凭“即梦2.0”推断为同名视频模型。两版本分别选择，不自动升级。网页与App分别记录实际入口、任务模式和账号可见功能。

## 独立资料卡A：Seedance 2.0

- 依据：[Seed官方发布页，2026-02-12](https://seed.bytedance.com/en/blog/official-launch-of-seedance-2-0)，本次已读取正文。
- 模型发布能力：文本、图片、视频和音频输入；发布说明列出最多9图、3段视频、3段音频，以及15秒多镜音视频输出；支持视频编辑和延长。
- 可用于本项目的表达方法：把角色、场景、道具、动作和摄影参考分别说明；连续动作保留发起、接触或避让、反应及终态；多镜写清观看顺序和跨镜状态。声音与画面按事件对应。
- 时长与数量仅作为发布能力记录；网页/App实际档位、组合上限、模式、声音开关和上传方式尚未查看，不能将这些数字全部填成账号已经开放的设置。
- 15秒是本页明确列出的输出能力；更长单次请求（如25秒）未获本页证明，应标“未核实”，不能仅凭发布页断言所有入口绝对不支持，也不能通过更换版本、延长或裁切冒称原请求已满足。
- 没有依据禁止2.0使用时间描述，也不要求所有任务填满15秒。首尾帧、普通参考、中间状态图能否同时使用，由具体模式证据确定。

## 独立资料卡B：Seedance 2.5

- 依据：[Seed官方发布页](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)，本次已读取正文。
- 模型发布能力：单次最长30秒，支持多轮延长；最多30图、10段视频、10段音频；提供白模、运动参考、按时间段组织及定向编辑等制作能力。
- 官方列出即梦网页选择Seedance 2.5的入口；这不证明用户当前账号和App具有相同功能或已开放全部额度。
- 表达方法：保持统一镜头基准；复杂段落可用阶段或时间段组织关键事件，局部编辑明确目标范围与保留内容，延展从实际源片末端状态继续。白模只承担空间或运动参考时，不继承其人物材质。
- 30秒是能力上限资料，不是每次都要写满的时长。跨镜台词和环境声不在每段重复起播。

## 入口与任务核对表

每次只核对本任务需要的组合。能力结论为“有据支持／有据不支持／未核实”，真实生成结果另记。

| 任务 | 应交付 | 仍需具体入口核对 |
| --- | --- | --- |
| 文生单镜 | 独立中文正文、动作起止、计划时长和声音 | 时长档位、画幅、声音设置及组合 |
| 图生单镜／首尾控制 | 单个时点的图片、起止相容说明、运动正文 | 输入角色、首尾与其他参考能否组合 |
| 多镜生成 | 镜号顺序、各镜观看任务、连续状态、生成素材与剪辑取用映射 | 所用模式与长度；正文时点不是逐帧保证 |
| 多模态参考 | 每份素材负责身份、服装、场景、比例、动作、运镜或声音中的哪一项 | 类型及总量、上传引用方式、职责语法 |
| 编辑 | 实际原片、改变对象／区间、保留对象／状态、预期终态 | 是否开放对应编辑入口及限制 |
| 延展 | 实际原片与末端观察、接续动作、声音连续性 | 延展入口、输入限制与输出长度 |

以下均未形成当前账号界面证据：独立负面栏、字符上限、分辨率枚举、素材总数与混用限制、引用标签精确写法、App与网页一致性。不要用第三方适配器或火山API字段补猜这些栏目。只有导航页或JavaScript外壳时，标未读到正文；[2.5提示指南入口](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)本轮仅保留为后续核对入口，不据外壳冻结策略。

## 从关键帧到真实输入

1. 用[19关键帧技能](../技能库/19_关键帧与冲击帧技能.md)区分姿态设计、首尾控制、普通参考和抽象插帧。多张设计图不自动成为可执行的时间序列。
2. 没有真实图时交文生正文或待图草案，附拟准备素材职责；不能登记为已经上传。用户必须使用某图时，缺图仍保留该依赖，不悄悄改为文生并声称完成。
3. 有图后实际检查起点和画风，记录“项目素材→真实文件→采用范围→实际入口位置”。二维图作身份参考与二维图硬锁首帧不是同一约束。
4. 不支持或未核实中间图控制时，保留设计帧供人工审核；按用户允许范围提出拆段、普通参考或后期插帧。不能把多个普通参考槽位说成逐帧位置。
5. “恰好两帧”需确认成片帧率及能精确放置的工具；只用提示词时属于目标。需要后期而用户要求原生时，明确冲突与备选，不伪称满足。

## 交付与版本

使用[06模型适配模板](../模板库/06_模型适配模板.md)。正文、输入映射、实际设置、后期和未知项分开；本地`negative_prompt`不是即梦同名输入。首帧已完成动作、同一说话者跨镜重读、单剑变剑雨等问题优先修正语义或素材，不靠加画质词掩盖。

项目本次采用的模型、入口、日期、官方依据和未核实项应随PROMPT附件冻结。本页后续更新不回写历史。四份完成文字范例见[Seedance双版本适配示例](案例/Seedance双版本适配示例.md)；它们未提交、未生成，也未证明用户界面可填写所有计划值。
