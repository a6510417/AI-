# 11_表演与声音连续性参考

用于对白、沉默、关系变化、喜剧节奏和多人听者反应。由06确定剧情信息，07安排镜头，09组织可复制正文；只查本次需要的分支，不把每个镜头都改成表演分析表。

本文件的短例均为本项目原创文字演示，采用三维国漫半写实仅为示例选择，未生成图片、视频或声音；不是既有IP剧情、已采用资产或平台控制能力证明。项目已采用风格、台词和声音要求优先。

## 一、先把情绪转成可见行为

“愤怒、悲伤、震惊”不能单独说明一场戏。选择人物此刻想从对方得到什么、遇到什么阻力、采取什么策略，再落到镜头能看见或听见的变化。人物可以压住表情、故意静止、不回答；不要求每句台词配手势、每个听者持续表演。

### 可裁剪的表演卡

| 项目 | 按本镜需要填写 |
| --- | --- |
| 剧情依据 | 已采用台词、人物已知信息、这一拍允许揭晓什么 |
| 目标与阻力 | 想得到的回应；阻止其直接达成的关系或事实 |
| 策略变化 | 如试探转为坦白；没有变化时写明保持的策略 |
| 可见／可听行为 | 目光目标、呼吸、重心、手部与道具、说话方式；选决定意义的动作 |
| 听者 | 谁收到信息，何时理解，回应或刻意不回应；其余人在做什么 |
| 段尾状态 | 是否仍持物、人物距离、下一句的说话权、未结束的声音 |

镜头只看见手时，不在正文中要求同时看清眼泪和嘴型。有关身体左右、持物和变化依据，接续[04_角色一致性管理技能](../技能库/04_角色一致性管理技能.md)；涉及交接、推搡或复杂位移，按需转[18_动作与特效导演技能](../技能库/18_动作与特效导演技能.md)。

## 二、对白：目的、话语归属与听者分开

保留用户要求逐字准确的台词、称呼和停顿意图，区分角色对白、画外音、内心声、旁白。口型与声音归属对应：镜内说话者可见口部时再检查口型，背身或画外说话不要求不存在的口型证据。无需把所有人都拍成正面说话。

**填写结构：**说话者与对象 → 原句 → 说话策略／可见行为 → 听者收到信息后的反应 → 声音与段尾衔接。

**完整最小视频提示词：**

> 三维国漫半写实，傍晚书房，窗侧暖光。黑发束髻、灰青长袍的青年站在桌前，右手仍压着桌上的一封信；短发、深蓝外套的少女站在桌对面。固定中景同时保留两人的脸和青年右手。青年先看信封，再抬眼看向少女，压低声音说：“这封信，你看过了？”少女不碰信，视线从信封移到他脸上，停一拍后回答：“只看了署名。”青年手指放松但仍压住信。对白按上述顺序由各自角色说出，其他时段没有额外台词；保留轻微室内底噪，台词清晰，无配乐。

**失败与最小返修：**两人同时说完整句时，明确一句结束后另一句再开始；需要有意抢话时，标注抢入词和仍可辨认的主句，不泛写“激烈争吵”。听者变成说话者时，修台词归属与口部可见范围，不先改台词或人物关系。

## 三、沉默：保留等待和有意静止

沉默可来自犹豫、拒绝、消化信息或等待；若用户要无法读出的表情，就保留含混。不要为“避免静态”自动加踱步、喘息、旁白或镜头运动，也不要求对白必须在固定秒数内开始。

**填写结构：**刚发生的刺激 → 人物选择不做什么 → 少量可见变化或明确静止 → 环境声音 → 沉默结束／继续的条件。

**完整最小视频提示词：**

> 三维国漫半写实，雨夜屋檐下。银灰短发、深绿披风的女子站在画面右侧，双手垂在身前，望着左侧紧闭的木门。固定胸部以上中近景。她听到门内钥匙轻响，目光停在门缝，嘴唇微启却没有说话，随后合上嘴，保持原位。门始终没有打开。雨滴沿屋檐落下，披风肩部只有细小雨珠；保留雨声和一次门内钥匙声，全段没有对白、旁白或配乐。结尾她仍看着门。

**失败与最小返修：**自动补出台词时，删去含糊的“似乎想说”并明确无对白；模型让人物来回移动时，锁定脚下位置和摄影机，把必要变化收在目光与嘴唇。若任务要求完全静止，则连这些细小动作也按要求省去。

## 四、关系变化：通过可见选择表达

先确定本段关系变化的程度。递物、允许靠近或移开视线可以表达态度变化，但不能自动升级成和解、爱情、原谅或新的剧情事实。

**填写结构：**原有距离／防备 → 一方试探 → 另一方允许或拒绝的具体动作 → 物品和空间变化 → 关系仍未解决的部分。

**完整最小视频提示词：**

> 三维国漫半写实，清晨山亭，柔和侧光。黑色短发、白色外袍的青年坐在石凳左端，右手握着自己的茶杯；长发低束、深灰长衣的女子站在石桌右侧，两人隔着石桌。固定双人中景。女子把另一只装有热茶的杯子放到青年左手边，松手后将手收回。青年先看茶杯，再把原本挡在旁边座位上的布包移到脚边。他没有伸手拉她，也没有说话。女子看向空出的座位，仍停在桌边。杯底接触石面的轻响、远处鸟鸣清晰，茶杯和布包在结尾保持新位置。

**失败与最小返修：**自动拥抱或告白时，把关系变化限定为“让出位置”，保持结尾未坐下；杯子无交接过程便换手时，按18补“落桌—松手—收回”，不要用强烈情绪词替代物理关系。

## 五、喜剧：建立预期、错位与反应

喜剧节奏不等于不停抖动、夸张大笑或每镜加音效。明确观众先知道什么、角色误判什么、哪一个事实打破预期，反应可以是短暂停顿或毫无表情。停顿长短是制作意图，不能当作某模型已经精确执行的帧数。

**填写结构：**可见预期 → 一次反差事件 → 角色发现顺序 → 可读反应／停顿 → 笑点后的状态。

**完整最小视频提示词：**

> 三维国漫半写实，明亮小院。高马尾、棕色练功服的青年站在石桌前，双手捧着一只带盖小木盒；圆脸、蓝色短袍的少女坐在桌对面。固定双人中景，盒子清楚可见。青年郑重地说：“见识一下我的宝物。”他把盒子放到桌上，掀开盒盖，里面只有一颗普通花生。少女先低头看花生，再缓慢抬眼看他，保持平静；青年举着盒盖的手停住，笑容逐渐收住。结尾花生仍在盒里。只保留这句对白、开盖声和院内轻风，没有笑声轨或额外爆炸音效。

**失败与最小返修：**笑点提前露出时，保持开场盒盖关闭；两人同时大笑时，改回指定的“少女平静—青年收笑”，不添加无关跌倒。用户指定有笑声或配乐时沿用，不把此例的声音选择变成全局禁令。

## 六、多人对话与声音连续性

### 可裁剪的声音交接表

| 项目 | 记录内容 |
| --- | --- |
| 台词归属 | 角色／旁白，原句，镜内或画外，单独说或有意重叠 |
| 声音身份 | 已采用音色／声音素材与职责；缺少时仅给文字方向，不声称声音已锁定 |
| 进入和结束 | 对应动作或台词节点，是否越过切点，是否允许被打断 |
| 空间与层级 | 声源位置、远近、房间／室外混响，主台词与环境声层级 |
| 连续状态 | 前镜仍在延续的雨声、引擎声、余音等；新镜不是无因重新启动 |
| 实现与验证 | 原生生成、已允许的后期或待核实；实际听检文件及是否准确 |

原生音频是用户要求时，在目标模式里核验对白、声效和同步能力；暂未确认则标为待核验，并保留原生交付目标。不能偷偷把对白改成字幕、把同期声音改成后期来声称完成。只有用户允许或本次制作范围明确包含后期时，才把后期作为实施方案；失败备选与实际已交付分开。

**完整最小视频提示词：**

> 三维国漫半写实，夜间驿站，桌面油灯照亮三人，窗外持续下雨。白发短须、褐色长袍的老者坐在桌北侧，黑发束髻、灰色衣服的青年坐在左侧，短发、蓝衣少女坐在右侧。固定三人中景，三人不换座。青年看向老者说：“桥还走得通吗？”老者等问题说完，看着青年回答：“水刚淹过桥面。”少女听到“淹过”时握紧自己面前的杯子，仍不发言；青年把目光移向窗外。原生生成两句对应角色的对白、雨声和轻微握杯摩擦声，台词清楚，雨声在两句之间连续。结尾三人位置与各自杯子归属保持不变，无新增台词。

**失败与最小返修：**少女重复老者台词时，明确她只听不说；雨声在反打切点突变时，检查是否仍为同一空间和时段，并在相邻任务保留相同环境声基准。不能仅凭提示词里写了“原生”就判定音频验收通过。

## 七、检查与交接

- 表情、手部或沉默是否承载明确的信息，而非无因增加动作？人物不能知道尚未发生或不在其知情范围内的事件。
- 台词、说话者、听者及声音归属是否一致？有意重叠和画外音是否有明确范围？
- 情绪变化是否误增关系结果；结束时的道具、位置和未完声音是否接续？
- 只要视频正文时直接给所需正文；不强制附表，不为静态图片添加连续对白过程。要冻结表演瞬间时转[19_关键帧与冲击帧技能](../技能库/19_关键帧与冲击帧技能.md)。
- 真实声音需听检台词准确性、身份、节奏、口型及连续环境声；文字检视只报告文字结果。
