## 一、近身：先写相互作用，再写快慢

每轮交锋形成一个可看见的闭环：**发起者与目标 → 接触、格挡或落空 → 对方回应 → 位置与重心结果 → 下一拍条件**。不用招式名称替代闭环，也不让两人同时完成互不相关的动作。

为主要角色分别选定优势距离、移动方式、主要攻击、防守反制和资源限制。角色差异来自已有体型、武器、性格与能力，不为丰富动作新增功法。已有设定允许时，用动作差异增强识别，例如一方保持长距离点压，另一方借掩体贴近；镜像、同门或刻意对称的对决可以采用相同动作方式。

| 要解决的问题 | 提示中写什么 | 看结果时检查什么 |
| --- | --- | --- |
| 发力轻飘 | 支撑脚、重心转移、进攻方向与作用部位 | 出手前后身体有支撑，受击方向与来力一致 |
| 各打各的 | 谁的动作迫使谁格挡、侧移或失衡 | 回应由前一动作触发 |
| 接触看不清 | 侧向中景或合适的三分之四角度，关键接触区可见 | 手脚属于谁、打中还是落空可辨 |
| “快”只剩模糊 | 保留关键攻防，压缩无用停顿；说明明确的位移和节奏 | 速度感没有吞掉接触和结果 |
| 摔抱变拥抱 | 双方朝向、抓握位置、支点及脱离方向 | 身体轮廓可分，抓握与位移有关系 |

一个镜头优先服务一个主要可见事件，事件内部可以包含必要的起手、接触和恢复。动作复杂度由参与者、接触次数、视角变化与时长共同决定，不规定所有模型每秒必须完成几招。接触过多、轨迹互相遮挡时，拆成可独立生成的短段，并记录前后站位。

动作细节与景别匹配：远景负责路线、距离和大幅位移；中景负责攻防接触；特写负责握持、破损或表情。远景中的微小指节变化不应成为决定胜负的唯一证据。

## 二、兵器：对象、握持、路径与反馈一起锁定

- 明确每件兵器的归属、数量、当前持握手、长度关系与形态；换手、脱手、折断要有可见事件。
- 写挥击轨迹和相对身体的位置，再写接触对象。剑刃、剑背、柄、盾面等区别仅在影响画面时注明。
- 落空、擦过、硬碰、压制、弹开各有不同结果。火花只用于适合产生火花的材质接触，布木碰撞不默认喷火星。
- 兵器特效有来源：剑体附着的能量随剑移动，发射后的剑气按已设路径独立前进；不能切镜后把一次释放变成新武器或无限投射物。
- 远程攻击交代取用或蓄力、发射方向、传播路线、命中/落点和剩余资源。能量规则服从已有世界设定。

**原创结构示例：**持杖者从画面右侧横向压住对手长刃；持刃者后撤半步卸力，刃尖仍朝左前方；杖头越过肩线后，对手才侧移到立柱外侧。接触只出现一次短促震动，双方各保留一件兵器，立柱成为下一拍的遮挡条件。

## 三、多人：让观众知道谁仍构成威胁

开场或必要的回到全景镜头交代主角、主要威胁、出口、障碍的位置。为镜头中需要追踪的对手使用稳定代号和可辨轮廓，其余远处人群作为分区群体，不要求每个人同时执行独立精细动作。

- 同一节拍优先呈现一个主要交锋，其余人交代逼近、绕行、受阻或等待空间；多人配合成立时写清先后与路线。
- 主角利用地形或对手位移改变包围关系，而非周围敌人无故停手。
- 掩体必须实际挡在对应两人的直线路径之间；同在柱子一侧的追赶者若没有被挡住，应由可见间距、起步先后或避让解释为何未追上，不能泛称所有人都被柱子拦住。
- 明确倒地、退场、遮挡中的人。镜头外不等于消失，下一镜的人数和威胁方向接续上镜。
- 群战特写之后及时恢复空间信息。跨越轴线、换边或大幅绕镜可以使用，但需要可见的重新定位，不能靠随机跳切掩盖。
- 大战场先定前景主战区、中景阵列、远景规模层。只有剧情关键人物需要独立连续性，远景规模不代替前景因果。

记录段尾：主要角色位置、朝向、持物、可行动状态、场景障碍与破坏。使用项目已有连续性记录，不另建与正式状态互相竞争的事实源。

## 四、宏大法术与特效：写发展过程和作用结果

特效不只是“金光、雷电、粒子、震撼”的并列。按本镜职责选择以下字段，不要求每条提示写满全部字段。

| 维度 | 需要决定的可见内容 |
| --- | --- |
| 来源与触发 | 由角色、兵器、阵法、天空或已存在装置启动；触发动作是什么 |
| 主体与数量 | 一个法相、一柄巨剑或明确的群体；哪个是主视觉中心 |
| 形态与材料 | 实体、半透明能量、体积雾、附着电弧；边缘、内部结构和不透明度各是什么 |
| 尺度与位置 | 与人物、山门、树冠、云层的比例；前中后景和遮挡关系 |
| 发展过程 | 预兆、聚集、成形、释放/移动、接触、扩散、消散或残留 |
| 路径与终点 | 从何处沿何方向移动，在哪里停止、命中、偏转或被阻挡 |
| 环境响应 | 风、云、水、砂石、建筑或植被在哪个位置、按什么方向改变 |
| 光照与曝光 | 效果照亮哪些表面；自身细节与人物是否仍可见；亮度如何随事件变化 |
| 声音节点 | 蓄力、位移、接触、余波各自对应的声音；有音频能力时才输出为生成控制 |
| 结束状态 | 剑体位置、法相是否仍在、阵法缺口、裂纹、尘土和人物状态如何延续 |

### 时间、空间与层次

发展过程应有因果，但不强制每次都从零开始蓄力。镜头可以从巨剑已经破云开始，前提是前镜或生成说明已提供这个初始状态。一个短生成段优先突出主要法术事件；多法术叙事按片段、时长与已确认能力安排，成形、破阵、反击、全景余波过密时分镜生成。时间码是编排意图，不能保证逐帧兑现；界面不支持的时长或镜头字段不能编造为参数。

通常先交代来源及形态，再看运动和接触，最后保留结果。尚未接触就出现无因果的地面爆裂应修正；若世界设定明确存在先行威压或远程震波，分别说明来源与传播，不能混成一次撞击。

前景用人物、地形边缘或建筑提供尺度；中景承载主要事件；后景用山体、云层和大气层次建立纵深。让主效果、次级碎屑和背景动势有主次。次级粒子服务运动方向、受力或气氛，不覆盖关键轮廓与接触点。

### 材质决定相互作用

| 效果类型 | 可以采用的交互 | 需要避免的误配 |
| --- | --- | --- |
| 实体巨剑、石质法身 | 遮挡、投影、接触阴影、反射、碰撞破坏；根据照明和尺度选择 | 剑未触地却在落点产生撞击坑；所有表面同样镜面反光 |
| 自发光能量法相 | 周边表面受染色光，云雾被照亮；按透明度保留背景透出及内部层次 | 一律要求与石像相同的厚重黑影；发光覆盖全部面部与体块 |
| 半透明灵气或体积雾 | 距离相关的遮蔽、光散射、穿插与流向 | 同时要求完全透明和完全遮挡；雾无差别糊满画面 |
| 剑气、冲击波 | 可追踪的源头、路径、波前和环境响应；是否可见由既有设定决定 | 只有屏幕震动与白闪，没有传播或结果；波前穿过一切却无解释 |

投光、投影和遮挡不是所有特效的统一套餐。纯发光或透明能量是否投影由世界规则、形态和画风决定；重点是同一效果跨镜保持一致。环境反馈可以夸张，但方向、接触位置及持续状态要自洽。

### 法相天地：先区分三种形态

- **身后独立法相**：本体大小与身份不变，法相在明确位置独立显现。指定外形锚点、数量、与本体的朝向/动作关系；避免被解释成第二个普通人物。
- **本体巨大化**：同一角色经历尺度变化；脸型、服装或装备如何随体型变化依据已有设定，不自动造出新甲胄。
- **环境化身**：云、水、山岩等汇成可辨形体；说明哪些介质转化、哪些仍属于环境、显现后的空间边界。

“显现”与“出招”可分成不同镜头。显现镜头保住尺度、轮廓和主从关系；出招镜头再说明目标、动作、作用范围与结果。不要默认追加神佛身份、额外头臂、无限高度、全屏符文或文字。

### 巨剑从天而降：保住一条可读路径

明确单剑/剑阵、实体/能量体、初始高度区域、剑尖朝向、下降路线和落点。先建立它与山门或阵法的关系，再表现破云、下压或下落；只有需要的阶段才进入本条视频。

破云的形状、剑体遮光/投光、地面风压、首次接触、结构破裂、尘浪外扩可构成层次，不必每项都发生。落点与受力方向相符，碎石先从受影响处产生；最终交代剑仍插地、停止在护罩上方、被偏转还是化散。剑雨需要单独设计数量层级和避让关系，不能从唯一巨剑无故复制。

## 五、尺度锚点：宏大必须在画面中有证据

“百丈、千丈、遮天蔽日”可表达故事设定，画面仍需可见的比较。优先选同一空间中的人物、门楼、树木、山峰或云层。尺寸说明和参考图不能矛盾，人物与巨物处于不同景深时，不能把屏幕像素高度直接当真实比例。

- **普通比例**：用可见地标说明位置，例如护栏到角色腰部；只在尺寸关系成立时这样写。
- **极端比例**：先设计一张人物/环境与巨物同框的比例参考，分别标明身份参考和比例参考职责。参考图本身的大小关系通过后再用于视频。
- **镜头选择**：宽景证明总体尺度，局部低角度镜头表现压迫，特写显示材质；不是每镜都要同时展示巨物全身与人物脸。
- **运动质量感**：巨大实体可以用缓慢起动、持续惯性和大范围反馈表达；能量体速度按既有能力设计，不能把“所有巨物必须缓慢”写成定律。
- **跨镜锁定**：沿用同一比例、场景地标与位置关系。若画面中巨剑缩成手持长剑、法相变成普通高个子，判为尺度失真，先修参考和构图。

## 六、UE5 半写实预设：把画风拆成可观察条件

### 先区分任务

**AI 图像/视频生成**中的“UE5、虚幻 5、次世代渲染”是审美参照，不代表实际启动引擎，也不保证启用 Lumen、Nanite、Niagara 或路径追踪。提示词优先写出材质、体积、光照与特效的可观察结果。

**实际 Unreal Engine 制作**属于另一条技术流程，需要项目文件、引擎版本、资产、材质、灯光、动画/特效系统与渲染设置；它们不由一段生成提示词代替。没有这类输入时，仅提供画风提示，不伪称已修改或验证真实引擎配置。

即梦网页/App 的参考类型、时长、声音、负面词和模型入口以用户当前可见界面及已确认能力为准。本库不把上游 Higgsfield、Seedance API 字段移植为即梦操作；未核实时给中文自然语言提示与所需素材清单，参数注明待核实。

### 半写实三维方案

这是用户选择该方向后可采用的预设，已有项目画风优先，不自动覆盖资产。

| 维度 | 默认表达 | 可按项目调整 |
| --- | --- | --- |
| 造型 | 保留既定年龄、脸型、服装轮廓，体块具有连续明暗与稳定空间体积 | 风格化比例、硬朗或柔和轮廓 |
| 材质 | 布料、皮革、金属、石材有不同粗糙度和高光响应 | 只增加有依据的局部磨损，不为质感新增伤势 |
| 光照 | 主光方向可解释，环境回光与接触关系协调，人物肤色和关键装备可辨 | 日夜、冷暖、特效投光随剧情变化 |
| 特效 | 能量轮廓、内部层次与环境交互清楚，发光亮度受控 | 允许夸张色彩和形态，不要求魔法服从现实材料 |
| 摄影 | 构图与景深服务动作；接触区清晰，运动模糊局部使用 | 单主运镜、适量震动、按动作切镜 |
| 连续性 | 同一角色、地点和特效沿用材质及色彩基准 | 光照变化不等于换脸、换材质或换渲染媒介 |

可复用的**原创风格短块**：

> UE5 次世代半写实三维动画质感。人物沿用已确认的造型与服装；体积由连续明暗表现，布料、金属与石材保持不同粗糙度和高光。光源方向与环境回光协调，关键动作和接触位置清楚。能量效果有可辨边界与内部层次，光照作用于邻近表面；背景细节和光晕强度服从人物与主要事件。

此块仍需具体角色、地点、动作与特效卡，不能单独当成完整生成提示。

### 冲突筛选

| 同时出现的要求 | 处理 |
| --- | --- |
| UE5 三维 + 禁止任何 3D/CGI | 删除来自不适用模板的否定词；如用户同时要求，先确定实际想保留的视觉结果 |
| 全片二维平涂 + 全片连续 PBR 写实着色 | 选定主媒介；有意混合时说明范围，例如三维角色配二维冲击插帧 |
| 决定性接触清楚 + 全程白闪/浓烟/强运动模糊 | 在接触和结果处留出可读时段，收缩遮挡范围 |
| 巨物轮廓完整 + 同镜极近面部特写 | 拆镜或调整景别；不要把互斥画幅任务交给同一镜 |
| 次世代画面 + 默认游戏 HUD、血条、镜头字幕 | 这些不是三维质感必需项，仅在用户或剧情明确需要时出现 |
| 写实材质 + 随镜改变金属/透明能量的本体属性 | 先锁定效果材质与形态；状态变化必须由可见事件支持 |

二维描边、漫画速度线或冲击帧可以作为用户指定的局部美术设计；它们与三维并非天然不兼容，但要写明出现镜头、持续范围和返回原画风的条件。

## 七、参考素材职责：让输入互补

| 素材 | 负责 | 不自动继承 |
| --- | --- | --- |
| 角色设定 | 身份、服装、轮廓 | 背景、动作、摄影机 |
| 场景基准 | 地理、建筑、关键障碍 | 图中偶然路人、未采用道具 |
| 动作视频 | 身体轨迹、节奏、发力关系 | 演员身份、服装、原画风 |
| 运镜视频 | 摄影机路径、速度及构图变化 | 人物动作和世界设定 |
| 材质/画风图 | 指定材质、着色或色彩层次 | 新角色、新剧情、新装备 |
| 比例参考 | 人物、巨物、地标的大小与相对位置 | 背景光照和整张图的全部风格 |
| 首帧 | 本镜已经存在的状态 | 尚未发生的终点或其他面板 |
| 尾帧 | 要抵达的可见状态 | 与起点无过渡关系的姿势或机位 |

每份素材点名对应对象及职责。不要承诺一个平台不支持的参考控制；多格故事板也不等于平台会自动逐格播放。若作为首帧上传的是单幅画面，提示重点是后续动作和变化，避免重写既定外观；若只是身份参考，仍交代本镜空间与行为。

动作参考优先选择主体轮廓、关键肢体和接触关系清楚的片段。单人动作迁移、多角色视频参考和分镜识别是不同能力，不能把单人模板限制扩大为所有模型规则。首尾差距过大时补中间状态或拆镜，不以更长形容词掩盖不可衔接的问题。

## 八、失败诊断：先修决定性症状

| 可见失败 | 优先检查 | 首轮修正 |
| --- | --- | --- |
