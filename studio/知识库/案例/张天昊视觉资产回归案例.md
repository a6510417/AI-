# 张天昊视觉资产回归案例

本例用于验证[03角色设计](../../技能库/03_角色资产设计技能.md)、[04一致性](../../技能库/04_角色一致性管理技能.md)与[19视觉交付](../../模板库/19_视觉基准与图片交付模板.md)能否做出有因果的设计并按版本复用。配色、发型、家族DNA及束腕比例来自本轮用户要求，只适用于本例；本文件是共享方法案例，不修改项目资产或采用基准，也不证明新设计已生成。

## 2. 从人物逻辑到可见选择

设计目标为“高颜值＋少年感＋机敏、有一点痞、生命力和胜负欲”。身份保留张家少年与现代人魂穿，未写外貌可按授权美术补全；少主身份不自动等于当前富贵或每处装饰都昂贵。原身家道与受欺处境、具体事件伤势另按原文和STATE时点选择。

| 依据／设计目标 | 生活或动作需求 | 本例可见方案与取舍 |
| --- | --- | --- |
| 俊秀少年、机敏而不服输 | 快速建立吸引力与辨识度，表情能够活起来 | 柔和少年颊面与利落下颌兼存；清醒眉眼、非长期冷脸；高束长马尾形成清晰轮廓。几何待真实图确认，不用成熟骨相或降低颜值表现年龄。 |
| 张家少年日常穿衣 | 先像常服，再满足行动；避免职业装备感 | 张家交领常服与轻战剪裁；窄袖、肩肘活动余量、轻腰封、分片／侧开衩衣摆与轻鞋靴；不靠护肩甲、厚皮或满身金属证明会战斗。 |
| 拳法、腿法等阶段动作需求 | 拳腕前臂力量线、伸肘、抬腿与旋身 | 轻型束腕与明确袖口边界，合理衣摆开衩；这些是未来动作适配设计，第一章未获得技能时不能把它们写成已会拳法的剧情事实。 |
| 墨青黑×暖赭动态角色色 | 手机端静态稳定，动作时有颜色节拍 | 主体墨青黑；暖赭藏在衣摆内层、侧开衩、少量领缘和腰带末端，转身或出腿才显露。避免满身高对比纹样。 |
| 同一张家、人物阶段不同 | 无需玉佩或大“张”字也能感到家族关联 | 共享固定领缘、特定交叠、轻腰封或低对比衣摆织纹中的少数结构。约10%～25%是美术语言目标，不是假定可由像素统计准确验证；角色仍保留各自年龄、经济和性格差异。 |
| 现代人魂穿、世界观仍是异世 | 用习惯表现行动效率，差异克制 | 袖口重新束紧、腰封打结更实用、领口略松、轻微不规整；不加现代手表、鞋或饰品，也不暗示异世人人如此穿衣。 |

本例元素预算：一级是少年脸和高束长马尾；二级是墨青黑×暖赭、张家轻战常服轮廓；三级是经独立设计与依据核对的张氏传承玉佩和轻型束腕；其他纹样与小金属退后。玉佩为用户指定设计方向，当前正面腰带三块嵌玉不自动变成原著传承玉佩，仍需独立确认形制、剧情归属和适用节点。禁止为填满角色包再加护肩、链条、多个玉佩、大量腰饰、流苏或复杂发冠。

## 3. 轻型拳法束腕专项

目标是日常衣袖自然延伸的轻束腕，兼顾拳—腕—前臂连续力量线；不是RPG重装备，也不因拳法自动要求护具。约70%织物／20%薄皮／10%金属或固定结构是本例视觉占比目标，不是现实材料配方、质量比或制造认证。

- 贴合前臂的墨青黑织物为主，外侧薄软革护片为辅，最多两条简洁固定带，最多一个小型暗铜扣。
- 手掌、腕关节和握拳线路清楚；袖口在束腕边界平整收束，不在护腕上方再堆一层袖套或厚袖褶。
- 不用复杂交叉绑带、大面积硬皮、厚甲、大图腾或法器光效。惯用侧只有已选且易保持的一处磨损或重缠差异；原文未明惯用手时不冒称事实。
- 先用文字检查握拳、伸肘、收势和旋身对衣袖的要求；得到图后检查结构，得到连续视频后才判断运动漂移。无实际生成时保持“方案可执行、动态待验证”。

## 4. 固化与后续引用演练

本轮不创建新项目资产。下列是下一次已授权视觉制作应遵循的行为，ID只使用届时真实登记结果：

| 对象 | 设计与固化职责 | 后续镜头允许的变化 |
| --- | --- | --- |
| 身份、脸发体型 | CHAR实际版本记录，脸几何绑定实际确认MEDIA版本、文件、视角和可见范围 | 表情、透视和自然发丝运动；不能另画一张更好看的脸替换身份 |
| 张家常服、束腕、玉佩 | 需要独立复用／替换时沿用PROP子类，分别存形制、材质、配色、尺度、识别点及允许范围；不造第二Registry | STATE明确时点的湿污、伤损、换装与携带；不能每条Prompt重新设计纹样和扣件 |
| 张家美术语言、技能机制 | WORLD／CHAR／PROP按职责保存；技能功能与特效形态分开 | 依已获技能和导演意图选择表现；一次性魂穿暗示不成为永久能力 |
| 静态与动态参考 | MEDIA实际取得文件与冻结提示词，参考绑定指定脸、服装、构图或起态职责 | 不借用该图不负责的背景、姿势、未来武器；新媒体生成未通过不能反改固定设计 |

生命周期依次区分设计候选、已保存、精确审核、正式采用锁定与被新版替代。固定版引用服装和组件，节点状态引用换装、持物和伤损；锁定说明、组件与参考绑定的机器字段只按[数据协议](../../docs/数据协议.md)。新版影响定位到真实直接引用者，不自动判废所有旧集，不改旧快照和历史审核。

当前没有正式采用的视觉MEDIA，也没有确认侧脸。本例不得写“侧脸已锁”“当前玉佩资产已固化”或把MEDIA-004候选当作正式身份锁。将来若先确认侧脸，正脸／3/4／另一侧面从共同眉眼、鼻唇、颧颊和下颌关系延展；眼距、脸宽等不能从单侧唯一反推的结构仍待确认，不能各视角独立美化。

## 5. 回归判定

文字行为检查的通过条件：设计选择能说明人物与动作原因；少年吸引力不被年龄要求削弱；无自动配刀、无把未知变事实；一级辨识元素清楚、束腕不过度设计；定妆、组件细节与技能表现解耦；同一固定版被实际引用；当前伤势、持物及一次性特效没有倒灌成永久设定。

实际媒体检查另行完成：共同面部几何、袖腕边界、暖赭动态显露、左右磨损和组件位置需看真实图／视频。图像文件与版本检查通过不证明上述质量，静态正面通过不证明背面或动态。当前结论是共享设计与引用方法已建立、现有候选差异已定位；没有生成新图、确认新脸、采用新版本或完成视频验收。
