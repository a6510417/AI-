# 13_转场分格与画面文字参考

用于回忆、梦境、蒙太奇、转场，以及分格、画中画、系统界面和精确文字。07负责故事顺序和剪辑单元，08处理观察位置与摄影运动，09输出本镜所需正文，10核验实际入口。只要普通单镜时不加载本文件的全部结构。

本文提示词为本项目原创文字演示，未生成或剪辑媒体。三维国漫半写实仅为例子选择，不覆盖项目已采用风格；任何界面文字、声音、转场能力仍需实际生成验收。

## 一、把故事时间、镜头和生成任务分开

| 可裁剪项目 | 写清什么 |
| --- | --- |
| 故事位置 | 现在、回忆、想象、梦境，或尚未确定的主观画面；不自动改变事实地位 |
| 播放顺序 | 观众先看到哪段，再看到哪段；与人物经历的时间顺序可以不同 |
| 出入状态 | 前镜结束的姿态、位置、道具与声音；后镜从哪个状态开始 |
| 连接依据 | 事件、目光、形状、运动、色彩或声音；只保留需要的一个或几个线索 |
| 实现方式 | 剪辑切换、叠化／合成、实际摄影运动、同场景遮挡，或故事内的形态变化 |
| 生成组织 | 每个SHOT仍是单个剪辑镜头，一次任务可承载多个SHOT；保留取用顺序与独立正文 |

回忆和梦境不是“可以补写任何剧情”的许可。已采用台词、角色年龄、服装、伤势及知情范围按对应故事时点处理，不从当前状态无条件继承。准确起止图片或接点需要时转[19_关键帧与冲击帧技能](../技能库/19_关键帧与冲击帧技能.md)。

## 二、回忆：触发和返回点清楚

不强制回忆必须褪色、加白边或慢动作。可以沿用主画风，通过已采用服装、场景和声音区分时期；确需色彩提示则标明范围。回忆后的伤痕、湿衣和持物以现在时的状态为准。

**填写结构：**现在时触发 → 回忆时点／依据 → 回忆只揭晓什么 → 连接方法 → 返回现在的位置与声音。

**完整最小方案及独立视频提示词：**

- **设计说明：**以下是原创“同一枚铜扣触发旧事”的三镜演示。现在时青年已成年，回忆为其少年时期；铜扣的缺口是匹配点。各镜独立生成后按顺序剪辑，剪辑任务未在本文执行。
- **现在镜：**“三维国漫半写实，夜间木屋，黑发束髻、深灰长衣的成年青年坐在桌前。固定手部近景，右手拇指轻擦左掌中的一枚旧铜扣，铜扣下缘有清楚缺口。桌边烛光在铜面移动，最后停在缺口朝下的构图；只有细微摩擦声与室内底噪，无台词。”
- **回忆镜：**“三维国漫半写实，白昼旧院。固定手部近景，短发、浅蓝衣袖的少年左掌摊开，一位穿褐色衣袖的长者将一枚下缘有缺口的铜扣放到少年掌心，松手后收回。少年右手轻轻合住左掌。日光柔和，保留铜扣轻碰掌心和衣袖声，无台词；不出现烛台或成年人的衣服。”
- **返回镜：**“三维国漫半写实，夜间木屋，黑发束髻、深灰长衣的成年青年坐在桌前。固定中近景，他左手仍握着旧铜扣，右手停在左掌旁；他抬眼看向桌对面的空椅，身体留在原位。桌边烛光照亮侧脸，室内底噪连续，无台词。”

**失败与最小返修：**回忆角色年龄未变时，修时期资产与服装参考；返回镜铜扣丢失时，修现在时段尾到返回的持物。剪辑连接需要时分别对齐铜扣构图，不把“回忆”写成物体自身变形。

## 三、梦境与主观画面

梦境可以不遵守现实地理，但仍要有本段可辨认的视觉规则。不要在没有依据时把梦中事件记录为现实资产变化，或自动以惊醒收尾。

**填写结构：**主观归属 → 已授权的不可能变化 → 保持的视觉锚点 → 本段结束／是否返回现实 → 声音范围。

**完整最小视频提示词：**

> 三维国漫半写实，主观梦境，一位黑色短发、白色长裙的女子站在浅水覆盖的空旷庭院。固定全身宽景，她与脚下倒影清楚。女子保持站立，周围石柱慢慢向上漂离地面，水面倒影中的石柱却仍停在原位；女子低头观察倒影，没有惊叫或奔跑。只有石柱发生这种变化，她的身体、衣服和双脚不变形。柔和蓝色环境光，微弱水声带悠长回响。结尾石柱仍悬浮，本镜不切到现实，不新增其他人物。

**失败与最小返修：**所有物体无差别融化时，缩小超现实规则到指定石柱；自动惊醒时，明确止于梦内终态。需保持身份时保留对应脸型／衣服锚点，不用全局“画面完全不变”否定梦境变化。

## 四、蒙太奇：压缩时间，不丢镜头边界

每段展示一个变化或信息，不把多个地点同时挤进一张首帧。时间跨度与成果程度来自故事依据；练习蒙太奇不自动授予新能力。一次多镜生成或分段生成由10根据入口决定，各镜仍可独立取用。

**填写结构：**压缩目的 → 段落顺序与时间跨度 → 每镜唯一新增信息 → 重复的连接线索 → 最终状态。

**完整最小三镜方案：**

- **设计说明：**原创演示“同一天整理旧书房”，只表现整理过程，不以整洁程度暗示长时间跳跃；下列三镜按编号顺序硬切，扫帚声可跨切点延续，音频实现按任务允许范围确认。
- **镜一正文：**“三维国漫半写实，清晨旧书房，短发、灰色衬衣的青年站在矮书架前。固定中景，他将书架顶层的三本书依次取下并叠到桌上，顶层露出积灰。晨光从左窗照入，只有取书与木桌接触声，无台词。”
- **镜二正文：**“三维国漫半写实，白昼旧书房，短发、灰色衬衣的青年握着一把扫帚。固定地面近景，双脚保持在桌腿外侧，他将桌边灰尘扫向同一个簸箕，桌上叠放三本书的下缘在画面上方可见。灰尘少量扬起后落下，保留扫地声，无台词。”
- **镜三正文：**“三维国漫半写实，傍晚旧书房，短发、灰色衬衣的青年站在已擦净的矮书架前。固定中景，他把同样三本书逐本放回顶层，最后将最右一本扶正，退后一步看书架。窗外暖光降低，地面已清扫，扫帚靠在门边，只有放书与退步声，无台词。”

**失败与最小返修：**三地点／三时段融合时，将每镜正文分开提交或使用已核实的多镜模式；成果超出原文时缩回已授权变化。镜二灰尘不自动影响另一个故事时间中的人物状态。

## 五、剪辑转场、摄影过渡与故事内变化

| 类型 | 适合表达 | 容易混淆的地方 |
| --- | --- | --- |
| 剪辑转场 | 两个SHOT间硬切、叠化、形状匹配、声音桥 | “切到”不是摄影机穿越墙壁，也不要求角色连续变形 |
| 摄影过渡 | 同一SHOT内摇摄、跟随、通过现有遮挡揭示另一主体 | 不自动新增切点；机位必须有空间路径 |
| 合成转场 | 遮罩、画中画扩大、分格组合等画面组织 | 需明确层级／时段；文本意图不等于入口提供可控合成 |
| 故事内变化 | 瞬移、变身、传送门等世界事件 | 须有本轮来源或授权改编依据；可重复技能核对能力功能与时点，不能凭空拿来替代剪辑连接 |

一次性魂穿可有魂影和跨空间视觉，意识授艺可用能量金人示范；按其来源与授权、主观归属、学习内容、结束状态和现实承接检查，不要求主角已经拥有传送或召唤技能。若效果进入现实并改变胜负、伤势或能力，再按相应世界规则审核。主观段落不自动冻结外界时间；外部声音、变化或明确省略保持时间关系。

**可裁剪结构：**前画面终态 → 连接对象 → 机位是否连续 → 后画面起态 → 声音衔接 → 验收点。

**剪辑匹配的完整最小例：**

- 前镜正文：“三维国漫半写实，室内圆木桌上有一只白瓷茶杯，固定俯拍特写，杯口居中，茶水因刚放下杯子产生轻微圆形涟漪，涟漪逐渐减弱。暖窗光，只有轻微水声，画面不变化成其他物体。”
- 后镜正文：“三维国漫半写实，夜间庭院，固定仰拍特写，满月居中，薄云从月前缓慢飘过，月亮始终为天空中的月亮。冷蓝夜色，只有院内夜风声，没有茶杯或桌面。”
- 连接说明：按杯口与月亮的圆形位置进行两镜硬切；这是剪辑设计，不能在单条视频里把茶水化成月球并声称等价完成。

**同镜摄影过渡的完整最小例：**

> 三维国漫半写实，白昼回廊。黑发束髻、青色长衣的青年向前缓慢行走，摄影机从他左侧腰部高度平稳跟随，始终在回廊可通行区域。途中一根已有木柱从画面右侧经过并短暂遮挡青年，摄影机继续原方向移动，木柱退出画面后露出仍沿原路行走的青年与前方石门。光照、服装和持物状态保持连续，无切镜、瞬移或新人物；保留连续脚步声和风声。

**失败与最小返修：**硬切被生成成融化时，拆成两个明确SHOT；一镜跟拍被自动剪切时，修连续空间与机位路径，必要时减少遮挡。用户要求一镜到底时不能私自改成剪辑转场；确需备选则与原目标分开说明。

## 六、分格与画中画

先确认是最终画面布局、参考故事板，还是希望顺序播放的多个镜头。静态宫格可以表现多个时点，但必须标明各格职责；如果模型只应接收一张起始图，应先准备对应单格，不能默认其会拆格按序播放。

**可裁剪布局卡：**画幅 → 区域数量与边界 → 各区人物／时点／内容 → 阅读或播放顺序 → 共用身份与分区独立变化 → 文字与声音归属。

### 最终静态分格图

**完整最小图片提示词：**

> 竖幅漫画页面，上下两格等宽排列，中间为清楚的白色格间，不出现格号、字幕或气泡。两格都采用三维国漫半写实。上格为白昼小院中景：短发、灰衣少年蹲在木箱前，右手刚掀起箱盖，左手扶着箱侧，神情专注；下格为同一场景稍后的手部近景：灰衣少年的右手托着从箱中取出的红色小木鸟，左手仍扶着箱侧，箱盖已打开。两格少年服装和木箱形制一致，上格箱中木鸟仍被箱沿遮住，下格只出现一只木鸟。每格各自是一个静止瞬间，不把两格融合为同一空间。

**失败与最小返修：**分格人物串到另一格时分区生成再按已允许的合成流程排版；作为参考时明确“借身份／构图”，而非保证生成模型按上下格自动播放。

### 同时发生的画中画

**完整最小视频提示词：**

> 横幅画面，三维国漫半写实。主画面是雨夜房间，短发、深蓝毛衣的女子坐在桌前，右手拿手机贴近耳边，听完后说：“我在门口等你。”右上角有一块边界清楚的矩形小窗，约占画面宽度四分之一；小窗显示同时发生的街边场景，黑发、灰色外套的青年站在路灯下，将手机贴在左耳，只听不说。两块画面各自保持固定机位，不相互穿插人物；女子台词属于主画面，背景保留较轻的雨声。结尾青年点头，主画面女子仍坐着，没有提前走到门口。

**失败与最小返修：**小窗被理解为房间实体显示器时明确最终画面叠加区域；边界持续漂移时说明原生效果待验证，只有任务允许合成才给分区制作备选。要求原生声音时仍按原生处理，不因画中画就自动改后期配音。

## 七、系统界面与精确画面文字

区分世界内屏幕／法术界面、角色主观系统层、观众字幕、对白气泡和后期标注。同一句文字的职责不同，会影响位置、遮挡和可读时长。准确文字先记录逐字内容、标点、顺序与对应对象；不要让模型自由“补全系统数值”或添加新能力。

### 可裁剪文字卡

| 内容 | 决定什么 |
| --- | --- |
| 逐字文本 | 精确字符串、行序、允许／禁止增删；变量值从哪里取得 |
| 归属和区域 | 谁看得到；贴屏幕、悬浮面板、气泡或观众层；跟随哪个对象 |
| 版式层级 | 主标题、数值、说明；安全边距、背景对比；无需无依据指定字体文件 |
| 变化节点 | 何时出现、哪一项改变、何时消失；静态图只表达一个数值状态 |
| 实现路径 | 原生生成待实测，或任务允许的后期文字／界面合成；不得混淆完成状态 |
| 验收 | 逐字、标点、数字、顺序、归属、遮挡及持续可读性；图像识别结果仍需核对 |

**原生系统界面的完整最小视频提示词：**

> 三维国漫半写实，清晨石室，黑发束髻、白色练功服的青年站在窗侧，双手自然垂下。固定腰部以上中景。一块半透明青色矩形系统面板在他右前方显现，面板朝向摄影机，边界稳定，不覆盖脸部；这是角色可见的悬浮系统界面，不是背景墙上的屏幕。面板只显示两行中文，第一行“任务完成”，第二行“获得灵石：3”。青年看向面板，嘴角稍微放松，面板亮度稳定后保持到结尾。两行文字逐字保持，没有新增奖励、图标、字幕或滚动字符。柔和窗光照亮人物，面板仅在右袖形成轻微青色回光；只有轻短提示音，无台词。

此正文是原生生成目标，不保证入口能逐字稳定实现。若用户要求原生界面或原生声音，继续核验该要求，不能把后期版本作为相同交付冒充完成。

**任务允许后期精确排字时的完整最小交接：**

- 底图正文：“三维国漫半写实，清晨石室，黑发束髻、白色练功服的青年站在窗侧，腰部以上中景，双手自然垂下，目光望向画面右侧。一块朝向摄影机的空白半透明青色矩形面板位于他的右前方，不遮住脸部，面板中央为干净无纹理的留字区；面板没有字符、数字或伪文字。柔和窗光和右袖微弱青色回光协调。这是一张系统面板已经出现的静止画面。”
- 排字交接：在该面板留字区叠入“任务完成”和“获得灵石：3”两行，首行为标题、第二行为数值说明，文字保持足够对比且不越出面板。若做视频，文字随面板平面和显现透明度一起变化；先审查人物、面板、遮挡，再逐字核对。此处只有制作说明，尚未执行排字或合成。

**失败与最小返修：**数字被改成30时只修指定数值与参考区域；字幕遮脸时修版式位置；出现陌生系统任务时删除自动补写内容。若原生逐字输出失败且不允许后期，明确报告该项未通过，可继续交付已完成的非文字设计，不假装所有要求已实现。

## 八、交接与检查

- 台账保留故事时间、播放顺序和镜头编号的不同职责；跨时间镜头不错误继承伤势或湿污。
- 一次任务覆盖多镜时给出各SHOT顺序、出入状态和取用关系；只要单镜正文时不强制附整个蒙太奇。
- 分格、画中画和界面作为最终合成设计时说明布局；作为素材参考时说明借用范围。没有实际图片则仍是计划，不登记为已生成MEDIA。
- 精确文字、原生音频、一镜到底等任务要求不因生成难而自动降级；给出失败位置和可接受的备选，是否采用由已有权限与用户要求决定。
- 真实验收需要观看跨切点、跨层边界与文字出现全过程；首帧正确不等于整段文字、声音和布局都正确。
