## 本地事实与默认选择

- 当前内置生图声明只有 `prompt`、互斥的 `referenced_image_paths`／`num_last_images_to_include`、`transparent_background`。画幅属于正文目标，实测尺寸另记；种子、蒙版、参考权重、可选模型或独立负面栏没有暴露，不能登记成已设置。
- 制作目的分文生图、参考生成与原图编辑，共用当前工具输入机制。三份适配示例保持同一单时刻接触，不假设像素级保留或身份稳定已成功。
- 本地工具原有快照清单记录文件哈希与大小；新绑定检查复用这一机制，并增加可选 `usage_id`／`expected_usage_id` 登记匹配。用途标识由实际查看后登记，工具不自动识别内容。
- 原SHOT规划时间不重叠。人工剪辑另记两份各6秒取用、1秒叠化、11秒覆盖，以及唯一连续声轨；数字是文字方案演算，尚无成片或听检。

工具结构、文字自洽、官方依据及真实媒体是四层证据。资料或标签校验通过不能代替真实看图、连续看片与听音，完整边界按[数据协议](数据协议.md)和[维护说明](../使用说明/02_维护与验收.md)执行。
