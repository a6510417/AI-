# IP 策划模板

用途：形成可进入世界、人物和剧情阶段的原创策划。对应 [13_创意策划技能](../技能库/13_创意策划技能.md)，全流程由 [12_IP总控](../技能库/12_IP总控技能.md) 组织。模板是填写骨架，不是已完成作品。

## 一、项目范围与记录

- 项目 ID、名称及本版：〔待填〕
- 本次目标、停止阶段及实际读取材料：〔待填：资料和范围，未读部分注明〕
- 受众、用途、题材与阅读体验：〔待填：区分用户要求与工作假设〕
- 阅读模式：〔待填：追读向／短剧口播／氛围短篇；写明是用户要求还是工作假设。未指定但要连载、网文或看下一章时用追读向。氛围短篇不套追读清单〕
- 读者每章或每集要等到的兑现：〔待填：翻盘、吃亏、获线索、关系推进或真相前进一步；不写市场数据〕
- 篇幅与制作限制：〔待填：章数／字数、主要人物／地点或其他约束；未知不猜成已确认〕
- 必留元素、不能改变的采用设定与创作权限：〔待填：资产 ID＋版本及授权依据〕
- 来源性质、采用状态与任务进度：〔待填：三项分开记录，原创采用仍是原创创作〕

## 二、故事核心

- 一句话故事：〔待填：谁为了什么，面对什么阻力，失败会怎样〕
- 核心主题：〔待填：将通过人物选择检验的问题〕
- 情绪体验与人物最终选择：〔待填：具体行为和代价〕
- 冲突的重复产生机制、升级方式与边界：〔待填：后续章节为什么仍有故事可讲〕
- 主引擎：〔待填：公开规则翻盘、期限压迫、信息差、身份欠账、能力代价或关系条件；一章只让一个引擎兑现。写入 PLOT 的 engine〕
- 关系欠账：〔待填：who 欠 owes 什么 what；没有则写没有。写入 PLOT 的 relationship_debts〕
- 本方案的具体特色：〔待填：机制、关系或视角；不写未经检索的市场唯一性结论〕
