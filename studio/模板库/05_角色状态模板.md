# 角色状态模板

用途：持续记录角色在具体剧情节点的预期状态，并与实际文字或媒体对照。对应[04_角色一致性管理技能](../技能库/04_角色一致性管理技能.md)；记录口径见[模板使用说明](00_模板使用说明.md)。

填法：基准、剧情预期、素材观察分开。主表保留外貌、服装、装备、年龄、状态五类；镜内发生变化时分别写动作前后。交接记录双方，不以播放顺序覆盖回忆或旧版本。

## 范围与角色基准

- IP 与 STATE 资产 ID＋版本：〔待填：独立文字任务可沿用旧记录号，登记工具时按统一协议〕
- 相关世界、人物、剧情基准引用：〔待填：各资产 ID＋版本；不以“最新”“同上”代替〕
- 项目、记录版本及本次任务：〔待填：首次登记、检查、更新或复核；范围〕
- 实际取得资料与来源：〔待填：正文、版本、出处及未回查部分〕
- 输入顺序、作品位置与故事时间：〔待填：按需区分；相对时间附参照点〕
- 实际查看的媒体及采用情况：〔待填：正式、候选、废弃或未知；真实覆盖区间〕
- 未检查范围：〔待填：缺失、遮挡、未取得或未实际查看的部分〕
- 固定组件引用与变更边界：〔待填：本节点选用 CHAR／PROP／WORLD 精确版本、MEDIA参考职责；固定形制与动态伤损、持物分开，新版替换不当作故事内换装〕
- 面部几何基准（涉及多角度时）：〔待填：实际确认MEDIA ID＋版本＋文件＋视角＋证据；本次可见结构和未知区域，没有确认图写未锁定〕

## 复核、实际操作与交接

- 修订稿文字复核：〔待填：已取得并检查的具体结果；只关闭该层问题〕
- 原文件与媒体状态：〔待填：分别写是否更新、生成、修改和查看；未执行注明〕
- 已完成与仍未知：〔待填：可检查范围及证据不足部分〕
- 给03的任务：〔待填：仅确需新阶段资产或补充基准时填写，否则写无〕
- 给分镜、提示词及质量检查：〔待填：可用状态、问题编号、受影响镜头和下一步〕
