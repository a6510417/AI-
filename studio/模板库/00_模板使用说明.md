## 二、怎么填写

1. 复制适用模板作为本次成果，保留原模板供复用；按任务决定成果名称与存放位置，不强制另建文件。
2. 先填写范围、来源、采用版本和创作权限，再填写正文。每个角色、地点、镜头或目标平台按说明复制相应单元。
3. 将所有〔待填：说明〕替换为本次结果。未提供的信息写“材料未提供”；有线索但不能判断写“待核实”；确实无此内容写“无”；未请求的提示词栏目直接省略；交付范围内确实不适用的内容说明原因，不能把未知写成不存在。
4. 表格行按实际资料增减，小任务可合并重复说明，但保留必交内容、来源及影响结论的缺项。可独立复制的提示词必须展开必要信息，不写“同上”或留下填空。
5. 新增设计按任务权限处理。只整理时不补造；设计草案可以给单一建议方案；用户明确授权采用时记录采用依据，不重复要求确认。创作内容始终不冒充原文。
6. 填写完检查相邻阶段的编号、版本、时间、空间、人物和道具状态。只交接实际完成的内容，不把计划或链接当作已执行技能。

## 三、统一记录口径

| 记录层 | 填写方式 | 边界 |
| --- | --- | --- |
| 来源性质 | 原文事实、梗概信息、分析推断、改编建议、用户设定、参考图观察、原创创作 | 附具体出处或创作依据。只承接报告时注明“上游标注、未回查”；参考观察限实际看见部分；旧标签不强制改名 |
| 采用状态 | 沿用来源、已采用改编、建议、待核实、已采用原创 | 与来源分列；建议用于方案预览不等于项目采用，用户采用的原创也不变成原文事实 |
| 实际操作 | 分别写文字稿、原文件、素材查看／上传、请求提交、媒体生成或修改、结果检查的真实状态 | 每项注明对象及证据；未执行就写未执行，不用一个“已完成”代替全部层次 |
| 质量结论 | 通过、需修订、待核实、未检查、不适用 | 按11逐项限定版本和证据范围；不能用未检查代替通过 |
| 状态对照结论 | 符合、不符、待核实、不可见／未检查 | 按04比较预期与观察；不与设定采用状态混用 |
| 问题处理 | 待处理、已交修改稿、已实际应用待复查、复查通过 | 注明文字、文件或媒体层；04中的“修订稿”与“修改稿”均须指向具体新稿 |

来源与采用状态不替代[总导演的任务进度](../技能库/00_总导演技能.md)。“审查工作已完成”也不等于“被审成果通过”。

## 四、容易填错的地方

- 时间：输入顺序、作品顺序和故事时间按需区分；片中时长、原始素材长度和实际读演数据分开。跨镜对白按一条声轨计算，并行动作不重复加时。
- 空间：先写稳定观察参照，再写本视图的画面左右；反向视图不能改变场地关系。身体左右按角色自身判断。
- 图片：首帧描述动作开始前的一个瞬间，不能提前完成交接；参考外观图不自动成为首帧。
- 平台：语义正文、素材输入、参数、负面栏目与后期处理分开；没有实际图片标识就保留模板状态，不能编值。
- 检查：只有文字就做文字复核；未生成、未查看的媒体保持相应状态。方案完成、文件应用、生成返回和验收通过分别记录。

本库不预填虚构人物或假接口数据；需要示例时应放在待填表之外并明确标注“虚构演示，不属于项目资料”。

打斗、追逐、能力对抗或环境特效可使用15；简单单镜只取需要的字段，不强制全表。03／04／06／07中的动作补充不替代完整分镜的十一项、用户所需提示词与五类质检。可阅读 [动作与特效完整示例](../知识库/案例/动作与特效完整示例.md) 理解填写方式；示例的画风、平台与人物不是新项目默认设定，也不证明实际生成效果。

## 五、原创 IP 和本地工具使用

新项目具体成果写入工作区根 `projects/IP编号_项目名/`，工作资产使用 `assets/<TYPE>/<ID>/`，原稿、制作文件和交接包分别使用sources、production和deliveries；v1旧八目录按清单兼容读取，共用技能与空白模板不保存故事实例。资产采用 `IP编号-类型-序号`，旧编号只作别名；地点 LOC、场次 SC、剧集 EP 分开。跨资产引用必须包含 ID 与版本，事件引用同时保留所属章节版本；故事时间、章节顺序和镜头播放顺序分别记录。

本库 Markdown 是人读填写骨架。需要本地检查、快照与导出时，`asset.json` 及各结构文件只按 [数据协议](../docs/数据协议.md) 和工具创建的样板填写，不把表格标题当作一套新 JSON。操作见 [接口规范](../docs/接口规范.md)，采用与复核见 [资产管理规范](../docs/资产管理规范.md)。空白样板允许保留占位，项目成稿不得以占位和空数组冒充完成。

工作稿、不可覆盖快照和采用指针分开。保存新版本不会自动采用；导出只使用明确采用的快照；上游采用变化需复核下游，不能让“最新稿”悄悄替换原引用。七文件章节整体保存和采用。新增世界设定单列候选，审核并明确采用后再成为后续基准。
