# 00_快速开始

本体系包含中文通用Markdown资料和本地辅助工具。你可以向AI提供技能及材料完成创作，也可以用中文菜单管理资产与版本；两种方式可以配合使用。它没有自动连接视频平台。模型应先确认实际读到了什么，再产出成果。

在当前 Codex 工作区，优先使用[工作室日常使用](04_工作室日常使用.md)中的九项标准 skill。它们按任务实际读取下列中文手册；在其他环境继续提供所需全文。宿主发现、实际读取和工具执行分别报告。

按“选择当前阶段 → 加载所需资料 → 完成后保存交接”使用；下列路线按已有材料选择，不需要逐项执行。

**第一次做自己的项目，先用[从空项目到首章实操](03_从空项目到首章实操.md)**：复制创作请求，让AI建立文件、真实审核、采用并生成续作包，不要求你手写JSON。只想了解或使用单个阶段，继续看下文。

## 从零创作一个原创IP

1. 提供[12 IP总控](../技能库/12_IP总控技能.md)和[13 创意策划](../技能库/13_创意策划技能.md)全文，说明题材、读者、篇幅、已有想法和本轮停止点。
2. 先形成策划，再按总控安排提供02世界观、03角色、05地点及[14剧情规划](../技能库/14_剧情规划技能.md)。已有资料直接复用，不因新流程而重写已确定内容。
3. 用[15小说生产](../技能库/15_小说生产技能.md)按采用设定写章节七文件，交[16内容审核](../技能库/16_内容审核技能.md)检查。新增规则和关系先列候选，不能从正文默改世界基准。
4. 章节修订并采用后，用[17漫改桥接](../技能库/17_漫改桥接技能.md)组织原06—09技能，形成剧集、场次、镜头和提示词。

可直接复制以下启动请求：

```markdown
请使用我实际提供的《12_IP总控技能》和《13_创意策划技能》。
本次目标：形成一个可展开为两章短篇的原创IP策划，本轮停在策划。
阅读模式：〔追读向／短剧口播／氛围短篇；未填时请给一个明确建议并写明是假设。要连载或看下一章用追读向，不要默认写成慢热氛围短篇〕。
题材、读者与已有想法：〔待填；尚未决定的部分可以给一个明确建议〕。
创作权限：允许原创人物、冲突和场景；将新增内容标为原创设计，不伪称已有原文。
请先列实际读到的材料，随后交付策划、建议采用的基准和下一阶段需要的输入。
不要把尚未写出的章节、未执行的审核或未生成的媒体记为完成。
```

## 使用本地工具保存项目

按[部署说明](../docs/部署说明.md)启动本地工具，使用中文菜单操作。首次用“创建项目”和“新建各类空白资产”；续做先看“查看当前基准与待办”。工具使用本机已有Node.js，不安装第三方包；若无法启动，见[部署说明](../docs/部署说明.md)。

从工作区根的新工具入口创建项目，进入 `projects/IP编号_项目名/`，默认布局v2，工作资产在 `assets/<TYPE>/<ID>/`。工具可创建各类型骨架并登记ID，AI按技能和[数据协议](../docs/数据协议.md)填写实际内容。工具不替你写故事，骨架也不是已完成成果。小说阶段用“生成新对话续作包”，无需先做分镜；漫剧阶段可按已完成剧集导出，后续章节仍可继续写。

日常顺序是：**新建骨架并创作 → 检查 → 保存版本 → 实际内容审核并登记 → 绑定审核采用 → 续作或交接**。保存不自动采用；改工作稿不影响历史。章节七文件同版保存，审核绑定具体版本及校验值。上游换版本后实际复核：要跟随则修改并升版，保留旧引用则记录这次精确依赖的理由和证据。

熟悉终端时可直接执行[接口规范](../docs/接口规范.md)中的命令。导出的中文交接说明可交给原技能继续工作；新对话仍需提供技能正文和实际交接文件，不能假定它记得旧对话。

状态里的“工具待办为空”只说明保存、采用、审核和复核等记录情况。创作目标、预演、参考素材及成片任务仍按项目报告和实际结果判断。

## 已有小说：从一段材料开始

1. 选一篇短篇、一个章节或一段梗概，说明实际范围。没有原文时可以先做准备计划，不要求一次找齐全书。
2. 提供[00总导演](../技能库/00_总导演技能.md)与[01小说分析](../技能库/01_小说分析技能.md)的完整内容。可以附件上传，或直接粘贴；仅给文件名、摘要或目录不足以让模型执行正文规则。
3. 复制下面的启动请求并替换待填项。先做一个小阶段，检查是否忠实于你给的材料。
4. 保存成果，下次把成果正文、版本和未解问题交给下一技能。不要只说“上一阶段完成了”。

```markdown
请使用我附上的《00_总导演技能》和《01_小说分析技能》。

本次目标：先制定制作计划，并完成已提供材料的小说分析；本轮停在分析。
材料范围：〔待填：篇名、章节或梗概范围，正文附后〕。
已确认要求：〔待填：确有的时长、用途、画风；未定可写未定〕。
已有成果：〔待填：名称、版本与正文；没有就写无〕。
创作权限：本轮只分析，不把新增人物、关系、外貌或结局写成原文。

请先说明实际可读取的材料与技能，随后给制作计划及四项分析结果。
区分原文事实、推断和改编建议，保留出处；关键缺项标明影响，非关键缺项不阻塞可完成的分析。
只完成本次范围，不把计划中的下游任务记为已执行。
```

## 打斗、特效与三维画风

提供 [18动作与特效导演](../技能库/18_动作与特效导演技能.md) 和需要执行的下游技能，说明谁与谁交互、初始空间、关键动作／胜负、最终状态及已采用画风。先形成能读清因果的动作，再写摄影、特效和提示词；只做单镜时保留09的四项输出即可。填写骨架用 [动作与特效设计模板](../模板库/15_动作与特效设计模板.md)，可先看 [完整文字示例](../知识库/案例/动作与特效完整示例.md)。

若目标是即梦网页／App，提供当前选择的模型版本和参考素材职责；不知道版本也可先写草案，不猜最新模型，不套API字段。若选择UE5次世代质感，说明是AI视觉模仿还是真实引擎制作；本库新增示例采用前者、三维国漫半写实，其他项目仍以用户已采用目标为准。文字完成不代表已生成或验收动作效果。

## 连续推进的调用方式

你可以把若干阶段一次授权给总导演，并说明停止点。下面可直接作为多阶段请求使用：

```markdown
请使用《00_总导演技能》，根据我提供的原文和已有成果，推进到中文文字分镜完成。
已提供的技能正文：00、01、02、03、04、05、06、07。
制作目标：1集，约1—2分钟；画风尚未定。
允许你补足完成本版所需的普通视觉细节，标明为已采用改编；保留原文核心因果和结局。
缺少非关键资料时采用合理工作假设并标注；已有信息不要反复询问。
逐阶段形成真实成果，将来源、资产版本、人物状态和镜头编号贯通。
没有实际图片或视频时只交文字。到分镜停止，返回成果位置、当前任务状态及下一步所需输入。
```

只有声明“已提供”且实际可读的技能才能执行。如果环境不能自动打开相邻文件，把对应全文粘贴到同一对话或下一对话，再复制交接块；无需假装系统能自动调用其他模型。

## 从空项目开始自己的故事

当前资料与历史演练分开；历史教学案例从归档记录追溯，不作为当前创作项目。第一次做自己的故事，从[空项目到首章实操](03_从空项目到首章实操.md)进入；使用[独立模板库](../模板库/00_模板使用说明.md)复制空白骨架，再填你自己的内容。

## 常见疑问

- **必须在同一窗口吗？** 同一对话便于沿用上下文；新对话也能继续，只要提供本次技能全文、已采用成果、版本、未解问题与停止阶段。不假设新对话能读取旧对话内容。
- **需要把这些安装成技能吗？** 当前工作区已有九项标准项目技能入口，按[日常使用](04_工作室日常使用.md)调用；原中文手册也可独立提供。不修改个人技能库，跨环境复制时应连同工作区根的 `AGENTS.md` 和 `.agents/skills/` 一起保留。
- **菜单能自动写小说吗？** 不能。它管理已经填写的内容，检查结构、保存和采用版本、导出交接；创作仍由你与AI按技能完成。
- **采用就是人工审核通过吗？** 不是。它表示明确选择了生产版本，采用理由须写真实依据；AI审核和用户实际审阅分别记录。
- **提示词写完就能直接生成吗？** 通用正文可以作为准备稿；还要检查真实参考输入、具体模型入口和参数。含占位图片标识的模板不能直接提交。
- **为什么还有待验证？** 文字检查无法证明未生成的动作、画面或声音。可以完成文稿任务，同时准确保留媒体阶段的待办。

## 直接做关键帧、冲击帧或专项场景

提供[19关键帧技能](../技能库/19_关键帧与冲击帧技能.md)和本段动作，说明要单图、序列还是含视频的完整包。可这样请求：

> 给单柄巨剑从穿云到插地停稳的关键帧序列；每张只写一个瞬间，分别交独立中文图片提示词、视频正文和拟参考职责。三维国漫半写实，末尾保留剑体与裂纹；没有参考图，不假称已上传。

只要一张“剑刃相接图”就直接说单图，不必填完整分镜。[三组案例](../知识库/案例/关键帧与冲击帧完整示例.md)展示填写方式；[专项导航](../知识库/00_知识库使用说明.md)覆盖文戏、特殊运动与分格文字。

指定Seedance 2.0或2.5时提供实际入口与模式，使用[两版资料](../知识库/10_即梦2.0与2.5适配.md)。没有界面证据先完成中文草案，保留具体未知项。真实出图出片及观看结果另记。
