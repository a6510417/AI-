# 01_完整流程与交接

原创项目从[IP总控](../技能库/12_IP总控技能.md)进入；已有小说从[总导演技能](../技能库/00_总导演技能.md)进入。完整路线是创意策划→世界与人物→剧情规划→小说章节→内容审核→漫改桥接→改编→分镜→摄影→提示词→按需适配→质检。04一致性自资产建立后贯穿，用户人工审核按实际发生记录。路线可裁剪，不要求小任务跑全套。

日常使用按“选择当前阶段 → 加载所需资料 → 完成后保存交接”推进。技能是中文操作规则，只报编号或文件名不代表已加载；向AI提供本次技能全文与材料，或让它实际打开文件。多阶段任务写明停止点，逐阶段留下真实成果即可。

打斗、追逐、能力对抗或环境特效在拆镜前按需接入 [18动作与特效导演](../技能库/18_动作与特效导演技能.md)，先给动作因果、空间、效果阶段及状态出口，再交07／08／09。独立09任务可只读取18并补最小动作单元；已有动作设计直接复用，普通对白、静物和简单动作不强制新增阶段。18负责设计，11负责按实际证据验收，平台入口与版本由10核实。

12组织完整IP，00组织漫剧制作，两者通过已采用章节及桥接任务交接。16检查小说因果、设定与叙事，11检查漫剧文字、提示词及实际可见制作成果；两类审核保留各自范围。常规创作选择按用户已有授权处理，执行边界统一见[AI执行规范](../docs/AI执行规范.md)。

## 原创阶段先交什么

| 阶段 | 需要的实际输入 | 交付与进入下一步的条件 |
| --- | --- | --- |
| [12 IP总控](../技能库/12_IP总控技能.md) | 用户目标、创作权限、已有资料 | 明确阶段、停止点、采用基准与实际任务状态 |
| [13创意策划](../技能库/13_创意策划技能.md) | 读者、题材、规模与核心想法 | 可展开的故事承诺、冲突和主角目标；明确原创来源 |
| 02/03/05设定 | 采用策划与已确定约束 | 世界规则、人物动机关系与知情、地点空间基准 |
| [14剧情规划](../技能库/14_剧情规划技能.md) | 采用策划和设定 | 章纲、因果链、人物弧线、伏笔埋点与预期回收 |
| [15小说生产](../技能库/15_小说生产技能.md) | 采用设定、章纲和前章出口状态 | 正文、摘要、人物、场景、情绪、新设定、漫改建议七文件 |
| [16内容审核](../技能库/16_内容审核技能.md) | 七文件、真实依赖、章纲 | 问题位置、修改内容、复查证据和采用建议 |
| [17漫改桥接](../技能库/17_漫改桥接技能.md) | 已采用章节与改编目标 | 章节→EP→SC→SHOT关系、来源版本、事件与文字交接 |

正文出现的新规则、人物关系或关键道具先进入候选设定，经审核与实际采用后再更新设定资产。每章入口读取前章状态，出口记录人物认知、持物、世界变化和伏笔进度；倒叙按故事时间读取对应状态，不把播放顺序当成事件顺序。

章节到剧集允许一章多集或多章一集。地点LOC和叙事场次SC分开；每镜保留原十一项，并补所属EP、SC、章节版本、事件和视觉描述。完整字段见[数据协议](../docs/数据协议.md)，不要另造一套JSON名称。

## 本地版本交接

工作稿准备好后先检查，再保存不可覆盖快照；采用必须明确选择已经保存的版本及依据。依赖先保存和采用，再处理下游。章节七文件整体保存，不能用新正文搭配旧摘要。较新稿不会自动替换已采用版本。

新资产可用工具生成各类型骨架，由AI填写；审核完成后登记针对精确版本的范围、问题和证据，采用时绑定审核编号。新正文或新版本需重新审核，不能复制旧通过记录充数。

采用上游新版本后查看下游复核提示。可以在有明确内容依据时保留历史曾采用版；需要跟随新版时实际修订下游并保存采用。导出会保留精确版本和完整依赖，不自动追新，也不输出未采用草稿。

把导出的 `交接说明.md`、结构化JSON、来源版本清单及对应技能交给下一对话。若只提供摘要，下一阶段应标明未回查原始材料。工具操作说明见[接口规范](../docs/接口规范.md)。

小说阶段直接生成 `续作说明.md` 与 `续作信息.json`，不要求先做分集、分镜。漫剧可以按已完成剧集导出，范围外章节仅因必要来源依赖入包时不扩展播放范围。已复核保留旧引用应记录精确影响项的理由和证据；上游再次变化重新核对。

| [08摄影](../技能库/08_摄影运镜技能.md) | 镜头卡与布局约束 | 五项摄影与可复制描述 | 固定／移动、观察侧、路径、清晰范围与切点 |

| [10按需适配](../技能库/10_模型适配技能.md) | 统一稿及明确或候选入口 | 目标正文、输入映射、配置或受限模板 | 能力证据、实际素材值、取舍、配置就绪状态 |
| [11质量检查](../技能库/11_质量检查技能.md) | 实际成果、采用基准与范围 | 五类检查、问题、建议、修改版本 | 问题位置、证据、复核层次及未看范围 |

两类并行可节省重复工作：世界观足够后，角色与场景可分别建立；文字剧本修订时，可同步整理已明确的状态变化。依赖尚未形成时保留缺口，不编一个“上游已完成”。

## 通用交接块

```markdown
本次使用技能：〔待填：文件名及实际可读正文〕
任务目标与停止阶段：〔待填：具体输出〕
实际输入：〔待填：名称、版本、章节／镜头范围，正文或可访问位置〕
本轮采用基准：〔待填：来源事实、已采用改编，待选建议另列〕
关键状态：〔待填：故事时间、人物版本、持物、场景状态、声音等相关项〕
硬条件与已允许调整：〔待填：明确约束，未知不要假定授权〕
尚缺材料及影响：〔待填：具体缺项，或无〕
预期交付与完成标准：〔待填：可以从成果核查的内容〕
请返回：真实成果正文／位置、采用版本、已完成范围、未解决项和下一阶段输入。
```

## 发生修改时，只同步受影响部分

例如把一镜的“阿青持药”改为“老周已持药”，先确定这是修复错误还是改变剧情：

1. 对照原文、采用剧本和变化事件，确认该镜应有状态。
2. 更新相关状态行、分镜卡和提示词；这些文字实际写入后才记为已同步。
3. 若首帧或视频已经存在，另列需重查或重做的素材；改文字不会自动修改图像。
4. 11只关闭已看到并检查过的修订层，00分别更新“修订文稿”和“媒体复查”两个任务。

摄影、画幅或声音要求改变也按同样方法追踪，不因一个词改动就无故重做所有阶段。

## 技能、模板、知识库如何配合

- 先用技能决定应做什么、如何判断，再从[模板导航](../模板库/00_模板使用说明.md)选择对应填写骨架；涵盖角色、场景、分镜、提示词、状态、适配、质检、策划、章纲、章节包、连续性、内容审核、漫改桥接及修仙系统爽文。按本轮范围选用相应模板条目，填写骨架由模板库维护。机器字段以[数据协议](../docs/数据协议.md)为准。
- 按任务查[镜头语言库](../知识库/01_镜头语言库.md)、[风格词库](../知识库/02_风格词库.md)或[光影词库](../知识库/03_光影词库.md)。词库提供选项，不自动替代用户偏好或世界设定。
- 写小说或短剧前，先确定追读向、短剧口播或氛围短篇，再查[追读向写法](../知识库/04_追读向小说写法.md)、[短剧口播与卡点](../知识库/05_短剧口播与卡点.md)和[写法诊断清单](../知识库/06_写法诊断清单.md)。用户要氛围短篇时不套用前两份。策划还要选一个主引擎和留下的关系欠账，见[类型引擎与关系张力](../知识库/07_类型引擎与关系张力.md)。穿越、修仙、系统升级同时用[升级循环](../知识库/08_修仙系统升级循环.md)和[爽文模板](../模板库/14_穿越修仙系统爽文模板.md)。可以借鉴常见修仙类型元素，但不整段、整章或连续台词照搬，也不把示例专有设定自动写成用户项目事实。这三项写入 PLOT；知情、持物和伏笔写入 STATE 的对应数组，并带章节事件引用。
- 普通用户界面稿不需要API配置。确需API时才采用10的接口格式要求，且只使用对应入口核实过的字段。
- 动作与特效按需使用 [设计模板](../模板库/15_动作与特效设计模板.md) 和 [三维画风参考](../知识库/09_动作特效与三维画风参考.md)。原十一项分镜、四项提示词和五类质检保留；动作附加资料是人读交接，不改变现有机器协议。示例的三维国漫、UE5视觉类比和即梦入口不是全局默认，来源及版本边界见 [来源与许可](../docs/动作特效开源来源与许可.md)。
- 不要求换成多代理或多个模型。一个模型依次读取技能、产出并传递正文，也可以完成全流程文字工作。

## 关键帧与生成输入的衔接

18动作设计 → 按需19选帧 → 09图片与视频正文 → 10实际输入适配 → 11分层验收。简单单图可直接19→09，已有设计无需重做。

[19](../技能库/19_关键帧与冲击帧技能.md)交付用途、唯一时点、前后状态、独立图片正文和输入职责。真实镜头已有SHOT时，镜头图片提示词可保存为PROMPT，真实图进入MEDIA，下游视频PROMPT引用实际需要的图；角色定妆尚无真实SHOT时，提示词留在MEDIA附件或制作文稿，不为登记提示词虚构SHOT。待制图计划不伪造MEDIA。故事镜头不回指自己的衍生成果，附件与所属资产一起冻结。

中文交接在十一项后展示摄影、状态、声音等扩展内容，并列出随包附件；机器数据与文字使用同一采用快照。工具导出成功不表示图像已生成或所有参考可被即梦接受。

## 实际生成与剪辑交接

内置生图先查[14适配卡](../知识库/14_内置生图适配.md)，选定模式、具体输入和验收条件。每次实际生成或返修追加[17台账](../模板库/17_生成与返修台账模板.md)，取得结果后填候选文件及区域／时码；采用与复查理由可追溯到精确PROMPT版本。MEDIA绑定由工具检查文件与可选用途，画面内容另验。

取得视频、声音后按[18剪辑模板](../模板库/18_剪辑取用与转场交接模板.md)交接入出点、成片位置、重叠及连续声轨。SHOT规划和最终手动剪辑并列，附件提供人工执行方案。每集REPORT将基准与采用结果列正式引用，未采用尝试保留文本定位；失败证据若需随包则放报告附件。先检查、保存，再按实际授权采用与导出，工作稿更新不改旧快照。
