# 04_工作室日常使用

在当前工作区打开 Codex，直接说明任务、项目和停止阶段；也可用下表中的 `$技能名` 指定入口。项目规则位于工作区根的[AGENTS.md](../../AGENTS.md)，九项标准技能位于 `.agents/skills/`。各入口读取必要中文手册，不把25项全部列为每次必读。

用户无需启动本地程序、打开终端或操作菜单。当前 AI 读取真实状态后，通过 `studio/bin/studio.mjs` 调用管理与制作命令，并整理可读成果；中文命令别名保留，无参数或 `--help` 仅显示帮助。

## 可直接使用的请求

图片资产：

```text
使用 $comic-image-assets，为当前项目制作我指定角色的图片资产。
先读取采用状态、当前视觉基准和实际参考图，保留身份与本次服装。
按需要选择文生图、参考生成或原图编辑；结果检查后报告可用用途和未验证范围。
本轮停止在图片资产交付，不提交即梦视频任务。
```

视频提示词：

```text
使用 $jimeng-video-prompts，把指定的已采用剧情片段写成即梦视频分镜和运镜提示词。
模型沿用我本次指定的2.0或2.5；入口不明确就列待核验项。
每镜给独立中文正文、实际参考图及职责、起止状态和检查点；本轮只交提示词，不上传或生成视频。
```

剪映交接：

```text
使用 $comic-capcut-post，根据提供的真实视频、声音和取用方案整理剪映专业版后期交接。
沿用指定画幅、台词和声音路径；记录素材与成片两套时间、字幕/UI、混音及导出要求。
本轮环境不能实际操作剪映时，交具体可执行方案，明确工程制作和视听检查尚未执行。
```

只读复盘：

```text
使用 $comic-production-retro，只读分析本轮真实尝试和采用结果。
按实际成本、耗时、可用素材量和失败原因给下一轮建议；没有样本的指标保持未知。
不修改项目采用记录，不执行新的生成或发布。
```

## 日常制作顺序

当前 AI 读取目标及[共通执行规则](../docs/工作室执行规则.md) → 查看状态 → 读取所需采用快照和实际文件 → 完成本次制作 → 按用途检查 → 按已有权限保存、绑定审核采用并交接。只有需要对应操作时才执行，不因打开项目而重新生成或重新采用。

视觉描述从[19视觉基准模板](../模板库/19_视觉基准与图片交付模板.md)选用当前设计；人物文学档案中的旧视觉建议须对照取舍。清单注明观察时间，不沿用过时数量。无真实镜头时，角色定妆词留在图片附件或制作文稿，不虚构SHOT/PROMPT。

声音承接[21声音模板](../模板库/21_声音制作模板.md)，剪辑承接[18取用模板](../模板库/18_剪辑取用与转场交接模板.md)和[22剪映交付模板](../模板库/22_剪映工程与成片交付模板.md)。发布前核对[23来源与发布](../模板库/23_素材来源与发布检查模板.md)，制作后填[24复盘](../模板库/24_生产与发行复盘模板.md)。没有对应任务时不强制填表。

账号入口、声源、渠道规格和额度由当次材料及实际核验决定。
