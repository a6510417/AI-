# 即梦分镜与视频提示词

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 写独立中文正文读[09提示词工程](../../../studio/技能库/09_提示词工程技能.md)；指定2.0/2.5或具体输入方式读[10模型适配](../../../studio/技能库/10_模型适配技能.md)与[双版本资料卡](../../../studio/知识库/10_即梦2.0与2.5适配.md)相关分支。 |
| 条件补读 | 需要拆镜才读[07分镜](../../../studio/技能库/07_分镜导演技能.md)，设计摄影才读[08运镜](../../../studio/技能库/08_摄影运镜技能.md)；打斗接触/特效读[18动作](../../../studio/技能库/18_动作与特效导演技能.md)；关键帧读[19关键帧](../../../studio/技能库/19_关键帧与冲击帧技能.md)。已有分镜复用，只修受影响内容。 |
| 填写骨架 | [04提示词](../../../studio/模板库/04_提示词模板.md)或[06适配](../../../studio/模板库/06_模型适配模板.md)简版；正式SHOT用[03分镜](../../../studio/模板库/03_分镜模板.md)保留十一项。 |

只要单条正文就给正文及必要输入/未知项，不扩为完整分镜包。逐镜保留起态、过程、结果、摄影、声音和取用关系；入口版本、网页/App模式与真实槽位分开，无界面依据不猜标签或API参数。只有实际执行并取得结果才登记提交、返回和媒体验收。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
