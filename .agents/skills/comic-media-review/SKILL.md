# 媒体检查与返修交接

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 定位被查确切文件/版本、采用基准和可用检查方式；读取[11质检](../../../studio/技能库/11_质量检查技能.md)相关验收项。 |
| 条件补读 | 人物跨图跨镜一致性读[04一致性](../../../studio/技能库/04_角色一致性管理技能.md)；小说因果/设定才读[16内容审核](../../../studio/技能库/16_内容审核技能.md)。小说图片先核对相关正文、当前设计与唯一时点，再比实际提交和图片。 |
| 填写骨架 | [07质量检查](../../../studio/模板库/07_质量检查模板.md)；小说图片用[19视觉交付](../../../studio/模板库/19_视觉基准与图片交付模板.md)相关条目；返修用[17台账](../../../studio/模板库/17_生成与返修台账模板.md)，剪辑取用用[18交接](../../../studio/模板库/18_剪辑取用与转场交接模板.md)。 |

检查范围依实际文字、单图、抽帧、连续视频、听音或成片观看分别记录。问题定位文件、区域或实际时码，给最小返修及复查范围；无新结果不关闭媒体问题。只读审查不重写媒体；已授权修订则执行本次范围。正式记录按接口规范绑定精确审核与版本，章节门禁不冒称全片验收。

人物审查按04区分固定基准、剧情预期和素材可见状态。多角度比较实际确认 MEDIA 版本的眉眼、鼻唇、颧颊、下颌与下巴关系；漂亮不证明同一人，遮挡和透视需先判断。服装、道具与武器按精确组件版本核对，问题归因区分时点选错、锁定组件冲突、提交漏传、生成未遵循和合法设计替换。复杂绑带、小扣和袖口堆叠可列动态风险；只有实际视频证据才能报告已发生漂移，不用机器文件检查替代几何或导演质量判断。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
