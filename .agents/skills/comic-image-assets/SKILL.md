# GPT图片资产生产

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 按本次对象读[03角色资产](../../../studio/技能库/03_角色资产设计技能.md)或[05场景资产](../../../studio/技能库/05_场景资产设计技能.md)相关方法；实际生图/编辑再读[内置生图适配](../../../studio/知识库/14_内置生图适配.md)。 |
| 条件补读 | 跨图基准或设计变体读[04一致性](../../../studio/技能库/04_角色一致性管理技能.md)；复杂正文读[09提示词](../../../studio/技能库/09_提示词工程技能.md)；首尾、关键姿态或冲击帧读[19关键帧](../../../studio/技能库/19_关键帧与冲击帧技能.md)。小说图片回查本用途相关正文、时点与可见硬要求，不直接复制跨章汇总提示词。 |
| 填写骨架 | [19视觉交付](../../../studio/模板库/19_视觉基准与图片交付模板.md)按单图裁剪；完整角色包才用[01角色模板](../../../studio/模板库/01_角色模板.md)，场景包用[02场景模板](../../../studio/模板库/02_场景模板.md)；实际尝试用[17台账](../../../studio/模板库/17_生成与返修台账模板.md)。 |

单图、基准核对或编辑只交本次所需成果；逐文件明确参考职责，编辑先看目标图，复查修改处与保留项。静态检查同时对照剧情依据和最终提交稿，列不可见部位及可用用途；未生成或未看图分别标明。无真实SHOT时提示词留MEDIA/REPORT附件或制作文稿，不造镜头链。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
