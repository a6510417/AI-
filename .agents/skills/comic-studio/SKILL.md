# 漫剧工作室总控

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照及直接相关的纠错和未解决记录。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 确定用户目标、当前阶段与停止点；已有项目先读状态和所需采用快照。跨阶段任务再读[00总导演](../../../studio/技能库/00_总导演技能.md)或[12IP总控](../../../studio/技能库/12_IP总控技能.md)。 |
| 小说接入与理解 | 读取[01小说分析](../../../studio/技能库/01_小说分析技能.md)，区分原稿接入、用户授权的全篇／完整范围分析和局部取材；长篇按01分批提取、归并及综合，不提前套用单集改编取舍。 |
| 条件补读 | 从零策划、小说续作按阶段读取13—16；选章漫改读06的A—N权限、视觉机会和短剧导演方法，需要正式桥接才读17，内容审核读16。单项图片、视频、质检或工作室制作转专项入口。 |
| 填写骨架 | [流程与交接](../../../studio/使用说明/01_完整流程与交接.md)中的交接单元；本次所选阶段的唯一模板。 |

已有多阶段授权就逐阶段交真实成果，保留采用基准、当前进度、阻塞、证据范围和下一输入。单项任务不搭建全IP流程。

执行小说到剧本、镜头与提示词的连续制作时读[AI制作流程](../../../studio/docs/AI制作流程.md)：由当前 AI 选择章节／事件、生成请求文件、读取有界上下文并完成创作，再用现有资产登记、审核和采用闭环。用户不逐项写 JSON 或提示词；本地命令不调用模型，也不代执行 Skill。需要可恢复的跨阶段进度才创建制作任务，按已有成果裁剪阶段；故事圣经复用 WORLD、PLOT、CHAR、LOC、PROP、STATE 和章节摘要，不另建同义资产库。缺少普通创作细节时在权限内补全并记假设，结构检查成功不得代写内容审核通过。

候选登记前执行制作检查，按问题回查来源，调用有确定依据的候选修复并再次检查，再正常导入。需要连续状态时只提取本轮范围的结构初值和变化、指定精确状态位置；旧自由文本保留未知，不默认推断状态一致。工具无法确定的剧情和语义问题由当前 AI 修订，只有关键取舍矛盾才按已有规则暂停。修复不保存、不自动升版，不代替导入后针对精确快照的实际审核。

本工作室短剧默认60—120秒、手机端观看。选章改编回查原文与必要前后文，摘要负责定位；按06识别低文字权重的视觉机会，明确A—N权限，按戏剧单元分集。先写有效场面，再用[25导演决策模板](../../../studio/模板库/25_短剧改编与导演决策模板.md)提取取舍、八个导演功能和登记内容；八功能不等于八段固定模板。已有资产按身份、服装、道具、技能机制与特效职责读取精确版本，剧本只提出真实新增需求。

在已有权限内直接完成动作、反应、环境和视听创作，保护本轮核心事实、人设与能力时点，具体边界由06维护。内容审核按16分别判断因果、人物／取舍、观看节奏、视觉表达与制作可行性；用户目标未达交实际修订。采用与结构通过不能代替内容判断，文字设计也不能代替真实媒体检查。

优先写正式工作资产，必要并行只用一个声明过的暂存位置；交接复用准确冻结成果，不永久维护多套准备稿或同义完成报告。共享维护按声明范围修改，项目资产、审核、采用、历史和备份不随之改写；清理候选先列明，删除另按授权执行。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
