# 生产与发行复盘

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 读[24生产与发行复盘](../../../studio/技能库/24_生产与发行复盘技能.md)，核对周期、范围、台账和已取得发行数据。 |
| 条件补读 | 生成候选／返修／采用与生成耗时费用依据真实尝试记录；声音或后期耗时费用分别依据[21声音](../../../studio/技能库/21_声音导演与制作技能.md)、[22后期](../../../studio/技能库/22_剪映后期与成片交付技能.md)成果及[20资源记录](../../../studio/模板库/20_制片任务与成本模板.md)，不要求先有生成记录。有渠道数据才分析发行，只有用户报告时明确转述来源。 |
| 填写骨架 | [24生产与发行复盘](../../../studio/模板库/24_生产与发行复盘模板.md)，复用[17生成台账](../../../studio/模板库/17_生成与返修台账模板.md)证据。 |

请求、多候选、返修、实际采用与成片取用分别统计；没有样本的成功率和后台指标保持未知。交少量可验证改进和观察指标；复盘不自动改已采用资产、新增任务或发布。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
