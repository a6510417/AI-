# 制片排期与成本

先读[工作室执行规则](../../../studio/docs/工作室执行规则.md)，按用户目标、权限和停止点完成本次任务；实际项目先运行 `node studio/bin/studio.mjs status --project projects/IP编号_项目名 --json`，读取所需冻结快照。纯文字规划按提供材料交付，不制造项目、媒体或采用基准。

## 读取路线

| 路线 | 读取内容 |
| --- | --- |
| 最小必读 | 读[20制片与成本排期](../../../studio/技能库/20_制片与成本排期技能.md)；有实际项目再读状态和相关制作报告，纯规划只按提供依据列缺项。 |
| 条件补读 | 需要生成尝试/返修预算时取现有台账；要实际声音、后期或其他制作任务时转相应专项入口。 |
| 填写骨架 | [20制片任务与成本](../../../studio/模板库/20_制片任务与成本模板.md)；真实尝试用[17台账](../../../studio/模板库/17_生成与返修台账模板.md)。 |

交可执行任务、负责人、依赖、完成条件、时间/额度依据和停止条件。估算与实耗分开；优先代表镜头小样。尝试次数与金额／积分预算分别记录，不能把额度数字当次数；只有可靠的单次计费依据才能推算预算可支持的次数，不编平台价格。每次新增消费前，核对同单位已耗、在途未结算费用上界和本次费用上界不超过硬预算，不重复计已入账费用；无法确认该边界时暂停受影响的消费，继续准备工作。不自动支付、开通服务或运行媒体任务，也不建新任务数据库。

交付实际成果位置、采用基准、检查覆盖、未解决项和具体下一输入。来源和状态口径见[AI执行规范](../../../studio/docs/AI执行规范.md)；需要登记才读[接口规范](../../../studio/docs/接口规范.md)与[数据协议](../../../studio/docs/数据协议.md)。
