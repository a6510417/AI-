# 历史记录

当前操作从[工作区入口](../README.md)开始。这里保留当时的材料及证据；其中命令、项目位置和检查数量属于各自记录时点。

- `docs/`：历史维护验收报告、原始日志和文件清单，保留原文。
- `legacy-assistant/`：重构前助手及完整 v1 项目的回退副本；其中一次性脚本是操作证据，不作为日常运行入口。
- [本地备份目录](../backups/)：完整实施前备份及校验清单。

旧项目可以用兼容入口显式读取；恢复前先在新副本核验，不覆盖正在制作的项目。历史报告的旧相对路径可能需要按当时目录上下文定位，当前共享文档和项目导航已使用新路径。
